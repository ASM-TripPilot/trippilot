# U0 Foundation — Business Rules

> 규칙 ID `BR-U0-##`. 판정 정본은 항상 서버 — 클라이언트 검증은 UX용 사본(차단 아님)이며 frontend-components.md에 대응 표기.

## 인증·계정 (BR-U0-01~09)

| ID | 규칙 | 근거 |
|---|---|---|
| BR-U0-01 | 가입·로그인 수단은 소셜 4종(Google·카카오·네이버·Apple)만. 이메일 가입·비밀번호 로그인 없음(이연) | Q1 · V1.1 |
| BR-U0-02 | 소셜 자격 증명은 `AUTH_CODE`(브라우저 OAuth)와 `SDK_TOKEN`(네이티브 SDK) 모두 수용. 검증은 전부 서버, 실패는 fail-closed 401 | Q3 · G-1 |
| BR-U0-03 | `(provider, provider_sub)` 기존재=로그인, 미존재=가입. 동일 소셜 계정 중복 가입 불가 | INV-S1 |
| BR-U0-04 | 제공자 이메일이 다른 활성 계정과 충돌하면 계정을 만들지 않고 409 + 기존 수단 안내 | INV-A3 · US-ONB-01 |
| BR-U0-05 | 가입 시 만 14세 이상 확인 필수(생년월일 또는 자기 선언). 미충족 422, 계정 미생성 | Q5 · INV-A2 |
| BR-U0-06 | 소셜 동의 거부·취소 시 계정 미생성, 안내 후 로그인 화면 복귀 | US-ONB-01 |
| BR-U0-07 | 액세스 토큰 1시간·무상태. 리프레시 90일·기기별 회전 체인·체인당 현행 1개 | Q6 · INV-R1 |
| BR-U0-08 | 회전된 리프레시 토큰 재사용 감지 시 해당 체인 전체 즉시 무효화(타 기기 불간섭) + 보안 이벤트 기록 | Q6 |
| BR-U0-09 | 로그아웃=해당 기기 체인만 revoke + 클라이언트 저장 토큰 즉시 삭제 | Q6 |

## 동의·약관 (BR-U0-10~14)

| ID | 규칙 | 근거 |
|---|---|---|
| BR-U0-10 | 필수 동의 3종: 서비스 이용약관 · 개인정보 수집·이용 · 위치기반서비스. 전부 GRANT 전 온보딩 진행 불가 | Q5 |
| BR-U0-11 | 마케팅·GPS기록·개인화 동의는 U0 온보딩에서 노출하지 않음(타입·API는 존재 — 후속 유닛) | Q5 · G-2 |
| BR-U0-12 | 동의·철회는 항목·약관 버전·일시·채널과 함께 append-only 증적으로 기록, 현재 상태는 최신 레코드 fold | INV-C2 |
| BR-U0-13 | 동의 증적은 계정 파기 후에도 보존(캐스케이드 제외), app DB 역할은 UPDATE/DELETE 불가 | V1.2·V1.7 |
| BR-U0-14 | 약관 버전 모델(현행판=effective_at 최신·reconsent_required)은 U0 수용, 재동의 UI 흐름은 이연 — 부트스트랩 분기 자리만 | Q5 · G-4 |

## 프로필·닉네임 (BR-U0-15~18)

| ID | 규칙 | 근거 |
|---|---|---|
| BR-U0-15 | 닉네임 2~20자, 활성 계정 간 소문자 무시 유일 | V1.5 |
| BR-U0-16 | 온보딩 진입 시 중복되지 않는 닉네임 자동 생성·기본값 채움 — 수정 없이 통과 가능 | US-ONB-03 |
| BR-U0-17 | 닉네임 저장 전 금칙어 검사(moderation) 통과 필수. 위반 시 저장 거부 + 대체 닉네임 원탭 추천 | US-ONB-03 · V1.6 |
| BR-U0-18 | 닉네임·취향은 설정에서 언제든 수정 가능(수정 시 동일 검증). 취향 변경은 `PreferencesUpdated` 이벤트 발행 | US-ONB-12 · C2 |

## 취향 (BR-U0-19~22)

| ID | 규칙 | 근거 |
|---|---|---|
| BR-U0-19 | 취향 7축 값 도메인은 V1.5 CHECK 그대로(domain-entities.md §PreferenceSet 표). 도메인 밖 값·구조 위반은 저장 거부 | V1.5 |
| BR-U0-20 | 각 취향 단계는 개별 '건너뛰기' 가능, 취향 구간 어디서든 '나중에 설정하고 시작'으로 일괄 탈출 가능. 약관·닉네임은 탈출구 대상 아님 | Q4 · US-ONB-11 |
| BR-U0-21 | 미설정 축은 NULL 저장(값 미생성), 조회 시 중립 기본값 파생: 이동=대중교통(보수), 예산=필터 미적용, 그 외=무가중치. 전 축 미설정이어도 개인화 응답은 완전 | US-ONB-14 · INV-PR2 |
| BR-U0-22 | 예산 총액 입력 시 구간(tier) 동반 필수, 총액은 양수 | INV-PR3 |
