# U0 Foundation — Business Logic Model

> 기준선(Q2 확정): main 머지된 Flyway `V1.0~V1.7` + `backend/docs/design/openapi.yaml`(20 경로) — 전 브랜치에서 스키마·API 변경 없음 확인(2026-07-17). develop의 크로스커팅 골격(TRIP-148 로깅·에러·이벤트버스)·피처 브랜치(TRIP-149 테스트 하네스·TRIP-150 아키텍처 게이트)는 기존 자산으로 수용.
> 기술 무관(technology-agnostic) 설계 — 구현 스택 결정은 `frontend/README.md`·backend 설계 문서 소유.

## 1. 소셜 인증 플로우 (US-ONB-01 · Q1·Q3)

**범위**: 소셜 4종(Google·카카오·네이버·Apple)만. 이메일 가입·비밀번호 로그인은 이연(스키마 V1.1 주석과 정합 — `PENDING_VERIFICATION`은 예약값).

**자격 증명 2종 수용(Q3)** — 클라이언트 획득 방식에 따라:

| 경로 | 클라이언트 | 서버 처리 |
|---|---|---|
| `AUTH_CODE` | 시스템 브라우저 OAuth (Google·Apple 기본) | 인가 코드 → 제공자 토큰 교환 → id_token/프로필 검증 |
| `SDK_TOKEN` | 네이티브 SDK 간편 로그인 (카카오톡·네이버앱) | SDK 발급 액세스 토큰 → 제공자 사용자 조회 API로 검증 |

두 경로 모두 최종적으로 **(provider, provider_sub)**를 확정한다. 검증 실패는 fail-closed(401).

**분기 로직**:
1. `(provider, sub)` 기존 존재 → **로그인**: 계정 상태 확인 → `DELETION_PENDING`이면 복구 안내 분기(§5), `ACTIVE`면 토큰 발급.
2. 미존재 + 제공자 이메일이 활성 계정과 충돌(INV-A3) → **409**: 기존 로그인 수단 안내, 계정 미생성 (US-ONB-01 예외).
3. 미존재 + 충돌 없음 → **가입**: 연령 확인 입력 필수(§2, 미충족 422) → `account`(즉시 `ACTIVE`) + `social_identity` 생성 → `AccountCreated` 이벤트(아웃박스) → 토큰 발급.
4. 사용자가 소셜 동의 거부/취소 → 계정 미생성, "로그인이 취소되었습니다" 복귀.

## 2. 연령 확인 (Q5 확정: U0 포함)

- 가입 시 만 14세 이상 확인 필수. 방식 2종(V1.1 `age_method`): `BIRTH_DATE`(생년월일 입력 → 서버 계산) 또는 `SELF_DECLARED`(체크 선언). `BIRTH_DATE`면 `birth_date` 필수(INV-A2).
- 미충족 → 422, 계정 미생성. 확인 시각 `age_confirmed_at` 기록.

## 3. 토큰 수명주기 (Q6 확정)

- **액세스 토큰**: 수명 1시간, 무상태 검증(서버 미저장).
- **리프레시 토큰**: 수명 90일, **회전 체인**(V1.4) — 갱신마다 구 토큰 `rotated_at` 마킹 + 동일 `chain_id` 신규 발급. 체인당 현행 토큰 최대 1개(INV-R1). 저장은 `token_hash`만.
- **다기기 허용**: 기기(=`device_id`)마다 독립 체인. 로그아웃은 해당 체인만 revoke.
- **재사용 감지**: `rotated_at IS NOT NULL`인 토큰 제시 = 탈취 신호 → **해당 체인 전체 즉시 revoke**(타 기기 불간섭) + 보안 이벤트 기록.
- **클라이언트 정합**: 동시 401 시 리프레시 요청을 single-flight 큐로 직렬화(자기 재사용 오탐 방지 — `frontend/README.md` HTTP 계층과 계약).

## 4. 온보딩 진행 상태 머신 (US-ONB-02~11·15 · Q4·Q5)

```
[가입/로그인 성공]
  → 약관 동의        (필수 3종: 서비스·개인정보·위치기반 — 전부 GRANT까지 '다음' 비활성. 건너뛰기 불가)
  → 닉네임           (자동 생성 기본값 채움 — 수정 없이 통과 가능. 건너뛰기 불가)
  → 취향 위저드 7단계 (스타일→예산→동행→활동→이동→음식→페이스)
       각 단계: 선택 저장 / '건너뛰기'=미설정 저장
       어느 단계서든 '나중에 설정하고 시작'=남은 단계 일괄 미설정 → 완료
  → 온보딩 완료      (profile.onboarding_completed_at 기록)
```

- 진행 위치는 서버가 판정 가능해야 한다(부트스트랩 `ONBOARDING_INCOMPLETE` 분기 → 남은 첫 단계로 복귀). 판정 근거: 동의 상태(필수 3종 최신 버전 GRANT 여부) → 닉네임 존재 → `onboarding_completed_at`.
- 미설정 축은 저장값을 만들지 않고(INV-PR2) 조회 시 **중립 기본값 파생**(US-ONB-14): 이동=대중교통(보수 추정), 예산=가격 필터 미적용, 그 외=무가중치. 전 축 미설정이어도 개인화 입력 응답은 항상 완전 — 일정 생성 무실패 보장.
- 건너뛴 취향은 홈·여행 생성 직전 점진 설정 카드로 재권유(구현은 홈/후속 유닛, 데이터 계약만 U0).

## 5. 계정 삭제 (Q8 확정: 30일 유예 + 재로그인 복구)

1. 삭제 요청 → `deletion_schedule` 생성(`purge_at = 요청+30일`, 계정 `DELETION_PENDING`, 활성 유예 계정당 1개 INV-D1) + 전 기기 세션 revoke + `AccountDeletionRequested` 이벤트(캐스케이드 개시 신호 — 실소비는 후속 유닛).
2. 유예 중 소셜 재로그인 → "삭제 예약 중" 안내 + **복구 선택** → `cancelled_at` 마킹, 계정 `ACTIVE` 복귀. 복구 거절 시 로그인 미진행.
3. `purge_at` 도래 → 파기 배치: 계정·연관 데이터 캐스케이드 삭제. **동의 증적(consent_record)은 법정 보존 — 캐스케이드 제외**(FK에 CASCADE 없음, V1.2 설계 그대로). 닉네임은 해제(전역 유일 인덱스 대응).

## 6. 부트스트랩 게이트 판정 (US-SHELL-01)

- 콜드 스타트 1왕복: `GET /bootstrap` → `BootstrapResponse{appUpdate, reconsent, session}` (openapi 기존 계약 그대로).
- **판정은 부수효과 없는 순수 함수** — 고정 우선순위: `appUpdate.FORCED`(강제 업데이트 화면·전 서비스 차단) > `reconsent.required`(재동의 — **U0은 분기 자리만, 흐름 구현 이연** Q5) > 세션 무효(로그인) > `ONBOARDING_INCOMPLETE`(남은 첫 단계) > 홈.
- 타임아웃(3초) 시 마지막 로컬 세션 기준 폴백 분기, 온라인 복구 시 재검증. 무한 스플래시 금지. 버전 확인 불가 시 게이트 미발동(페일오픈 — 게이트는 UX 안내).

## 7. 크로스커팅 스캐폴딩 (Q9 확정: 골격만)

| 항목 | U0 설계 수준 | 기존 자산 |
|---|---|---|
| 트랜잭셔널 아웃박스 | 테이블(V1.0) + 적재 규약(상태 변경과 단일 TX)까지. 릴레이 실소비는 후속 유닛 | V1.0 · TRIP-148 이벤트버스 |
| 구조화 로깅·오류 표준 | 상관 ID·표준 오류 응답 형식 규약 채택 | TRIP-148 |
| 레이트리미터 | 인터페이스·429 응답 계약만(openapi `RateLimited` 기존) | — |
| 금칙어 검증 | 닉네임 저장 전 검사 호출 계약(moderation) | V1.6 |
| 감사·법정 증적 | append-only 권한 분리(V1.7 grants) 그대로 수용 | V1.2·V1.7 |
| 위치 권한 | **프리프롬프트 프레임(재사용 UI)만** — OS 다이얼로그 실제 발화는 후속 유닛(탐색·여행 중) | V1.3(동의 상태) |

## 8. 기준선 정합 검증 (계획 항목 7)

**정합 확인**: 소셜 전용 MVP ✓(V1.1 주석) · 연령 2방식 ✓(V1.1) · 필수 3종 동의 ✓(V1.2 terms_type 존재) · 회전 체인 90일 ✓(V1.4) · 30일 유예+복구 ✓(V1.4 `cancelled_at`) · 취향 7축+중립 파생 ✓(V1.5) · 부트스트랩 3필드 ✓(openapi).
