# U3 AI Itinerary Generation — Functional Design Plan

> **유닛**: U3 AI Itinerary Generation — **C8 Itinerary Generation**(일정 생성 오케스트레이션). Place Data(C7)는 U1 소유, 솔버·LLM은 U2 경계 뒤(AI 서비스)

> **범위 주의(SCOPE.md)**: 설계 문서까지. 코드는 팀이 `backend/`·`frontend/`에서 직접 개발
> **선행**: U0(2026-07-17) · U1(2026-07-23) · **U2(2026-08-07 승인)** 설계 종료. U2가 확정한 경계 계약·BR-U2-01~16이 이 유닛의 전제다

B) U5(Archive)가 통째 소유 — U3는 이벤트만 발행하고 화면·복원은 U5 설계로 미룸

## Question 2 — 동선 재정렬 제안(h25 배너 + h28)의 지위 ★
