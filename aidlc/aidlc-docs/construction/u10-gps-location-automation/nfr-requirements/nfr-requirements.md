# U10 GPS·위치 자동화 — NFR Requirements

> **방침**: 얇게. U0·U1·U3·U4·U6 NFR과 상속 기반선(50 RPS · 99.9% · 재시도 없음 · 서킷 미도입 · security-baseline Full · resiliency Full · PBT Partial blocking)은 **그대로 승계**하고 여기 다시 적지 않는다.
> **FD 중복 금지**: 무장 5조건(BR-U10-02) · 리전 선택(09~11) · 판정 임계(12~19) · 배치 멱등·서버 우선(20~22) · 다운샘플·세그먼트·클램프(35~38) · INV-3(40) · 동의·강등·파기·법정 로그(42~48)는 **`functional-design/business-rules.md`가 정본**이다. 여기 있는 것은 그 규칙이 **얼마나 빠르게·얼마나 적게·어떤 조건에서 출시 가능한가**뿐이다.
> **결정 근거 (2026-10-12)**: U3·U4·U6 선례대로 **실장을 먼저 확인하고 실장을 우선**했다(실측 표는 `plans/u10-gps-location-automation-nfr-requirements-plan.md` Step 1). 답변 = Q1~Q14 **전부 권고안**(Q6만 B, 나머지 A) — 사용자 일괄 지시 "그럼 권고로 ㄱㄱ".
> **수치의 지위**: 아래 값은 FD 임계와 같은 지위다 — **설정·기준값이고, 조정은 규칙 개정이 아니다**(O-U10-2). "근거 없는 초기값"은 그렇게 표시한다.

## 0. 이 유닛에서 새로 생기는 축

| 축 | 왜 새로운가 | 상속으로 안 덮이는 이유 |
|---|---|---|
| **MOBILE** 배터리 | FD가 MOBILE-U4-05(연속 추적 없음)를 **철회**했다 | U4 배터리 근거("지오펜스는 한 자릿수 %")가 사라졌다 — 예산을 다시 세운다 |
| **STORE** 심사·신고 | TRIP-936이 끈 '항상 허용'을 다시 켠다 | U0~U6에 스토어 정책 축이 없었다(TRIP-935/936은 설계 밖 처리) |
| **SEC** 기기 안 위치 데이터 · 잠금 상태 실행 | 원시 좌표가 **기기 디스크에** 하루 수천 점 쌓이고, 앱이 **잠긴 기기에서** 깨어난다 | U0 SEC-09는 토큰만, U4 SEC는 서버 인가·잠금화면 본문만 다뤘다 |
| **REL** 자동 결과 큐 | 사람 입력이 아닌 이벤트가 회선 없이 생긴다(DEC-U10-16) | OFFLINE-U4-02(방문 체크 큐)는 보류 상태 — 이 큐는 그 보류의 **예외 하나** |
| **OBS** 오탐률 | 자동 기록의 품질은 사용자 정정으로만 드러난다 | U4 OBS는 발화/무발화, U6는 전달 — **정정률** 지표가 없었다 |

## 2. 성능 (PERF-U10-\*)

| ID | 요구 | 근거 |
|---|---|---|
| **PERF-U10-01** | **백그라운드 태스크 1회 실행 ≤ 10초**(벽시계). 그 안의 네트워크 요청 타임아웃 = 8초, 한 wake에 요청 최대 2개(자동 결과 배치 1 + 구간 보고 1). 시간이 모자라면 보내지 않고 큐에 둔다 | iOS가 위치 wake에 주는 실행 시간은 짧고 보장되지 않는다 |
| **PERF-U10-02** | 판정 리듀서·리전 선택은 wake당 **≤ 100ms**(기준 기기). 순수 함수라 6-b가 아니라 jest 벤치로 잴 수 있다 | 시간 예산 대부분을 네트워크에 남긴다 |
| **PERF-U10-03** | 다운샘플 + 인코딩은 하루 상한(20,000점)에서 **≤ 2초**(기준 기기). 넘으면 포그라운드 복귀 시점으로 미룬다(백그라운드에서 돌리지 않는다). 알고리즘은 NFR Design(O-U10-8) | MOBILE-U10-05 |
| **PERF-U10-04** | 서버 `POST /visits/auto-events`(항목 ≤ 50) **p95 ≤ 500ms** · `PUT /routes/{date}`(점 ≤ 2,000) **p95 ≤ 1s** · 구간 보고 **p95 ≤ 300ms** | wake 시간 예산(PERF-U10-01) 안에 들어와야 한다 |
| **PERF-U10-05** | 업로드 본문 크기 상한 — 자동 결과 배치 64KB · 경로 256KB. 넘으면 413 | 2,000점 인코딩 폴리라인 ≈ 수십 KB |
| **PERF-U10-06** | `DELAY` 서버 스케줄러 **5분 주기 · ShedLock 단일 실행 · 대상 = 열린 `GEOFENCE_ARMED` 구간이 있는 여행만**. 알림 지연 상한 5분 | Q12=A · FD §8 |
| **PERF-U10-07** | 실제 경로 레이어(i01·j01)는 서버가 준 다운샘플 세그먼트를 그대로 그린다 — 표시 전 다운샘플(PERF-U4-04)은 저장 시점으로 당겨졌으므로 **추가 다운샘플 없음**. 계획｜실제 토글은 재요청 없이 로컬 전환 | PERF-U4-02 개정 승계 |

## 5. 보안 · 기기 데이터 (SEC-U10-\*) ★

| ID | 요구 | 근거 |
|---|---|---|
| **SEC-U10-01** ★ | **기기 안 원시 표본·판정 상태·큐는 OS 데이터 보호에 맡기고 앱 수준 암호화를 하지 않는다.** 앱 샌드박스 안 **클라우드 백업 제외 경로**(iOS `Caches` · Android `cacheDir`)에 둔다. OS 퍼지로 잃으면 그날은 근사 표기(BR-U10-35 실패 폴백과 같다) | Q3=A · SECURITY-01 |
| **SEC-U10-02** | 기기 U10 디렉토리 전체 삭제 시점 = **L2·L3 토글 OFF(BR-U10-42) · 로그아웃 · 계정 삭제 요청 · 서버 `REJECTED_CONSENT`/409 수신(BR-U10-45)**. 로그아웃이 빠지면 같은 기기 다음 사용자에게 이전 사용자 동선이 남는다 | BR-U10-42 범위 확장 |

| **SEC-U10-04** ★ | **백그라운드 태스크는 토큰을 갱신하지 않는다.** 401이면 큐를 유지하고 포그라운드의 갱신 경로를 기다린다 — 동시 갱신은 재사용 감지(SEC-02)로 **세션 체인 전체를 무효화**한다 | U0 SEC-02 |

| **SEC-U10-06** | 신규 엔드포인트 4종(자동 결과 배치 · 되돌리기 · 경로 PUT/GET · 구간 보고)은 **객체 수준 인가**(소유 계정 아니면 404) + `slotKey`가 그 여행 일정에 속하는지 서버가 확인 | SEC-05 · SEC-U4-01 승계 |
| **SEC-U10-07** | 입력 상한 — 배치 항목 ≤ 50 · 세그먼트 수 ≤ 200 · 디코드 후 총 점 ≤ 2,000(+여유 없음) · 문자열 필드 길이 상한 · `occurredAt` 범위(BR-U10-21). 폴리라인 디코더는 상한을 넘으면 디코드를 멈춘다(자원 고갈 방지) | SECURITY-05 |
| **SEC-U10-08** | 킬 스위치(REL-U10-06)는 **가용성 장치**다 — 꺼짐이 동의·인가 판정을 대신하지 않고, 켜짐이 동의 없는 수집을 허용하지 않는다 | SECURITY-15 fail-safe |
