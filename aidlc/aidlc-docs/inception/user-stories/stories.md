# User Stories — TripPilot

> **정본 관계**: 기능·규칙 정본 = `docs/PRD/`(01~15) · UI/UX 정본 = Figma. 담백 제품 정의 = `docs/PRD/PRD-lean.md`. 페르소나 = `personas.md`. 요구 추적 = `requirements.md`(FR-*).
> **방법론(확정 결정)**: 에픽 = PRD 모듈(Q3=A). 수용기준 = **Given–When–Then**(Q5=A). 추적성 = **출처 PRD 모듈-스토리# + 연관 FR**(Q6=A). PRD 120 스토리를 정규화하되 공백은 채우고 부자연스러운 스토리는 다듬음(Q1=A+보강).
> **INVEST**: 각 스토리는 Independent·Negotiable·Valuable·Estimable·Small·Testable를 지향한다. GWT는 핵심 정상 흐름 + 주요 예외를 담고, 세부 규칙은 PRD 원문을 정본으로 상속한다.
> **범위(Q2=C·Q4=A)**: 1차 핵심 여정 9모듈(A·B·C·D·E·F·G·H·I)은 상세 전개. 후속 게이트 3모듈(J 어시스턴트·K 커뮤니티·L 공동편집)은 **에픽 헤더 + 인터페이스 계약만**(상세 스토리 후속 이연). 페르소나 = 4종(P1 혼자·미식 / P2 커플·휴양 / P3 친구·액티비티 / P4 가족·관광), '전체'=여행자 공통.
> **FR-SOLVER 분리 註**: 사용자 대면 일정 동작(에픽 E·F)은 스토리로 담되, **엔진 교체 전략(Phase 1 결정론적 솔버 → 향후 Bedrock)** 은 아키텍처 요구(`requirements.md` FR-SOLVER)로 유지하며 스토리로 두지 않는다.

## 에픽 A — 앱 셸 (모듈 01) · FR-SHELL · FR-CORE

#### US-SHELL-01 — 스플래시 분기
**As** 여행자, **I want** 앱 시작 시 세션·약관 상태에 따라 적절한 진입점으로 분기되기를, **so that** 내 상태에 맞는 화면으로 바로 들어간다.
- **정상**: **Given** 저장된 유효 세션과 최신 약관 동의가 있고 **When** 콜드 스타트하면 **Then** 스플래시(탭바 숨김) 후 홈 대시보드로 진입한다.
- **분기**: **Given** 유효 세션이 없으면 로그인으로, 세션은 있으나 약관 미동의/온보딩 미완료면 해당 단계로 분기한다.
- **예외**: **Given** 세션·약관 확인 네트워크 호출이 지연되면 **Then** 진행 표시를 유지하고 시간 초과 시 마지막 로컬 세션으로 분기하되 온라인 복구 시 재검증한다(ADR-0011).
- 출처: PRD 01-1 · 연관: FR-SHELL-01

#### US-SHELL-02 — 홈 대시보드
**As** 여행자, **I want** 홈에서 내 여행 상태·다음 행동·인기 장소·취향 맞춤 공개 기록을 한눈에 보기를, **so that** 다음에 뭘 할지 바로 안다.
- **정상**: **Given** 진행/예정 여행이 있고 **When** 홈에 진입하면 **Then** 여행 카드(목적지·기간·D-day·등록 숙소 수·일정 유무·진행률)·빠른 액션('여행 만들기')·인기 장소·취향 맞춤 공개 기록을 표시한다.
- **첫 사용자**: **Given** 등록 숙소·여행이 없으면 **Then** '예약 없이 AI로 먼저 일정 받아보기'와 '가고 싶은 곳 먼저 저장'(Case A) 진입을 노출한다.
- **예외**: **Given** 추천/커뮤니티 카드 데이터 일부 실패 시 **Then** 침묵 실패 없이 가용 카드만 우선 표시하고, 취향 부족 시 온보딩 설정 유도 카드로 채운다.
- 출처: PRD 01-2 · 연관: FR-SHELL-01 · FR-CORE-01
- 페르소나: 전체

#### US-SHELL-03 — 5탭 글로벌 네비게이션
**As** 여행자, **I want** 하단 5탭(홈·탐색·일정·기록·마이)으로 주요 기능에 바로 도달하기를, **so that** 헤매지 않는다.
- **정상**: **Given** 앱 사용 중 **When** 탭을 전환하면 **Then** 각 탭 루트(홈/탐색 랜딩[숙소·장소·여행자 일정 3진입]/일정/기록/마이)로 이동하고 각 탭의 이전 화면 상태(스크롤·하위 화면)를 보존한다.
- **여행 중**: **Given** 진행 중 여행이 있으면 **Then** 홈 활성 카드와 일정 탭이 동일한 '여행 중 활성 일정 허브'로 수렴한다.
- **예외**: **Given** 탭 루트가 0건 상태면 **Then** 빈 탭 대신 섹션별 빈 상태 안내를 노출한다.
- 출처: PRD 01-3 · 연관: FR-SHELL-01

#### US-SHELL-04 — 몰입 화면 탭바 숨김
**As** 여행자, **I want** 몰입이 필요한 화면에서 탭바가 숨겨지기를, **so that** '단 하나의 다음 행동'에 집중한다.
- **정상**: **Given** 스플래시·온보딩·입력 폼·일정 생성/편집·여행 중 실행·바텀시트/다이얼로그·어시스턴트 모달 화면이면 **When** 진입하면 **Then** 탭바를 숨기고 전체 폭 단일 CTA 또는 자체 하단 액션을 쓴다.
- **예외**: **Given** 탭바를 숨긴 화면이어도 **Then** 시스템 뒤로가기/닫기로 직전 탭 컨텍스트로 복귀할 수 있다.
- 출처: PRD 01-4 · 연관: FR-SHELL-01

#### US-SHELL-05 — 장소 우선 저장(Case A 온램프)
**As** P1·P3, **I want** 가고 싶은 장소(POI)를 먼저 저장해 두고 여행 만들 때 '꼭 갈 곳'으로 가져오기를, **so that** 장소 우선으로 시작한다.
- **정상**: **Given** 탐색 랜딩 '장소' 진입에서 **When** POI를 검색·저장하면 **Then** 이름·카테고리·지역과 함께 목록으로 보이고, 저장 POI는 위시리스트·필수 방문지 지정의 입력으로 재사용되어 여행 생성 시 '꼭 갈 곳' 시드가 된다.
- **잇기**: **Given** 저장 POI가 있으면 **Then** '이 장소들로 여행 만들기' 진입으로 여행 생성으로 이어간다.
- **예외**: **Given** 저장 POI가 0곳이면 **Then** 빈 화면 대신 안내 + 장소 검색 진입을 노출한다. (숙소 권역 역추천은 두지 않음)
- 출처: PRD 01-5 · 연관: FR-CORE-01 · FR-SHELL-02
- 페르소나: P1 · P3

## 에픽 B — 계정 및 온보딩 (모듈 03) · FR-ONBOARD

#### US-ONB-01 — 소셜/이메일 가입·로그인
**As** 여행자, **I want** 소셜(카카오·네이버·Google·Apple)이나 이메일로 가입·로그인하기를, **so that** 익숙한 방법으로 빠르게 진입한다.
- **정상(소셜)**: **Given** 로그인 화면에서 **When** 소셜 버튼을 누르면 **Then** 해당 OAuth로 이동하고 성공 시 제공자 고유 ID(sub)로 신규 생성 또는 기존 로그인 처리한다.
- **정상(이메일)**: **Given** 이메일 가입 시 **When** 이메일·비밀번호를 입력하면 **Then** 인증 메일을 발송하고 인증 완료 후 계정을 활성화한다(비밀번호는 해시 저장).
- **예외(중복)**: **Given** 이미 가입된 이메일이면 **Then** 중복 계정을 만들지 않고 기존 로그인 수단으로 유도한다. **Given** 소셜 동의 거부/취소 시 **Then** "로그인이 취소되었습니다"로 복귀하고 계정을 만들지 않는다.
- 출처: PRD 03-1 · 연관: FR-ONBOARD-01 · SEC-AUTH
- 페르소나: 전체

#### US-ONB-02 — 약관 동의(최초 1회)
**As** 여행자, **I want** 최초 1회 약관에 동의하기를, **so that** 필수 절차를 한 번에 끝낸다.
- **정상**: **Given** 최초 로그인 직후 온보딩 진입 전 **When** 필수 약관(이용약관·개인정보 처리방침)에 모두 동의하면 **Then** '다음'이 활성화되고 동의 항목·일시·약관 버전을 계정에 저장한다(마케팅 동의는 선택).
- **예외**: **Given** 필수 약관 중 하나라도 미동의면 **Then** '다음'을 비활성화하고 미동의 항목을 안내한다.
- 출처: PRD 03-2 · 연관: FR-ONBOARD-01
- 페르소나: 전체

#### US-ONB-03 — 닉네임 자동 생성·수정
**As** 여행자, **I want** 자동 생성된 닉네임을 쓰거나 수정하기를, **so that** 가입 직후 유효성에서 막히지 않는다.
- **정상**: **Given** 계정 생성 시 **When** 온보딩 닉네임 단계에 오면 **Then** 중복되지 않는 닉네임이 기본값으로 채워지고, 수정 없이도 통과할 수 있으며 "나중에 설정에서 바꿀 수 있어요"를 안내한다.
- **예외**: **Given** 닉네임이 2~20자 위반·금칙어·중복이면 **Then** 인라인 오류를 표시하고 사용 가능한 대체 닉네임을 원탭 적용으로 추천한다.
- 출처: PRD 03-3 · 연관: FR-ONBOARD-01
- 페르소나: 전체

#### US-ONB-04 — 위치 권한 고지·거부 허용
**As** 여행자, **I want** 위치 권한의 목적을 이해하고 거부도 할 수 있기를, **so that** 이유를 알고 결정한다.
- **정상**: **Given** 위치가 실제로 쓰이는 첫 맥락('내 주변 숙소 탐색'·'여행 중 실행' 첫 진입) 직전 **When** 도달하면 **Then** just-in-time 프리프롬프트 1회 후 OS 권한 다이얼로그를 호출한다(온보딩에서 강제하지 않음).
- **예외**: **Given** 권한을 거부하면 **Then** 등록 숙소 위치 기준으로 동작하고 "설정에서 켤 수 있습니다"를 안내하며 온보딩을 중단하지 않는다.
- 출처: PRD 03-4 · 연관: FR-ONBOARD-02 · LEGAL-01
- 페르소나: 전체

#### US-ONB-05 — 여행 스타일 설정
**As** 여행자, **I want** 여행 스타일(휴양·관광·액티비티·미식·쇼핑·자연·문화예술, 복수)을 설정하기를, **so that** 맞춤 추천을 받는다.
- **정상**: **Given** 스타일 단계에서 **When** 1개 이상 선택하면 **Then** '다음'으로 진행한다.
- **예외**: **Given** 미선택 후 '건너뛰기'면 **Then** 미설정으로 저장하고 다음 단계로 간다.
- 출처: PRD 03-5 · 연관: FR-ONBOARD-03
- 페르소나: 전체 (P1 미식 · P2 휴양 · P3 액티비티 · P4 관광 대표값)

#### US-ONB-06 — 예산 수준 설정
**As** 여행자, **I want** 전체 여행 예산 수준(저가/중간/고급/럭셔리 또는 총액)을 설정하기를, **so that** 가격대·비용 가중치에 반영한다.
- **정상**: **Given** 예산 단계에서 **When** 4구간 중 하나를 고르거나 총액을 입력하면 **Then** 러프 선호 값으로 저장하고, 여행 생성 시 정확 총액으로 수정 가능하며 (a) 1박 숙소 가격대 필터 기본값과 (b) 1일 지출 가중치에 반영한다.
- **예외**: **Given** '건너뛰기'면 **Then** 미설정 저장 → 숙소 탐색에 가격 필터 미적용(전체 가격대 노출).
- 출처: PRD 03-6 · 연관: FR-ONBOARD-03
- 페르소나: 전체

#### US-ONB-07 — 동행 유형 설정
**As** 여행자, **I want** 동행 유형(혼자·커플·친구·가족(아동)·부모님·반려동물)을 설정하기를, **so that** 동행에 맞는 추천을 받는다.
- **정상**: **Given** 동행 단계에서 **When** 유형을 선택하면 **Then** 저장하고 숙소 탐색 정렬·일정 생성 입력에 반영한다.
- **예외**: **Given** '건너뛰기'면 **Then** 미설정으로 저장한다.
- 출처: PRD 03-7 · 연관: FR-ONBOARD-03
- 페르소나: 전체 (동행 축 = 페르소나 정의 기준)

#### US-ONB-08 — 선호 활동 설정
**As** 여행자, **I want** 선호 활동(자연·역사문화·테마파크·맛집투어·카페·전시·야경·쇼핑·스포츠, 복수)을 설정하기를, **so that** 장소 추천 우선순위에 반영한다.
- **정상**: **Given** 활동 단계에서 **When** 복수 선택하면 **Then** 장소 추천 우선순위에 반영한다.
- **예외**: **Given** '건너뛰기'면 **Then** 미설정 저장.
- 출처: PRD 03-8 · 연관: FR-ONBOARD-03
- 페르소나: 전체

#### US-ONB-09 — 이동 방식 설정
**As** 여행자, **I want** 이동 방식(도보·대중교통·렌터카·택시·자전거, 복수)을 설정하기를, **so that** 동선·이동시간 계산 기본값에 반영한다.
- **정상**: **Given** 이동 단계에서 **When** 선택하면 **Then** 일정 생성 시 장소 간 이동시간 계산 기본 수단에 반영한다.
- **예외**: **Given** 미설정이면 **Then** 기본 이동 수단='대중교통'(가장 보수적)으로 처리한다(US-ONB-14).
- 출처: PRD 03-9 · 연관: FR-ONBOARD-03 · FR-SCHED-01
- 페르소나: 전체

#### US-ONB-10 — 음식 취향 설정
**As** 여행자, **I want** 음식 취향(한식·양식·일식·중식·아시안, 복수)을 설정하기를, **so that** 맛집 추천에 반영한다.
- **정상**: **Given** 음식 단계에서 **When** 복수 선택하면 **Then** 맛집·음식 장소 추천에 반영한다.
- **예외**: **Given** '건너뛰기'면 **Then** 미설정 저장.
- 출처: PRD 03-10 · 연관: FR-ONBOARD-03
- 페르소나: 전체 (P1 미식 강조)

#### US-ONB-11 — 온보딩 건너뛰기·이전
**As** 여행자, **I want** 온보딩 각 단계를 건너뛰거나 이전으로 돌아가기를, **so that** 첫 가치를 늦추지 않는다.
- **정상**: **Given** 취향 단계(5~10·15) 어디서나 **When** '나중에 설정하고 시작'을 누르면 **Then** 남은 취향을 일괄 건너뛰고 곧바로 홈/첫 가치로 진입하며, 건너뛴 항목은 미설정 저장·중립 기본값으로 동작한다.

#### US-TRIP-02 — 숙소 미등록 시작

- **정상**: **Given** 숙소 미등록 상태로 **When** 여행을 생성하면 **Then** "숙소 미등록" 상태로 표시하고, 여행지 중심으로 일정을 먼저 만든 뒤 동선 기준 숙소 추천을 받을 수 있음을 안내한다(1급 온램프).

## 에픽 E — AI 일정 생성 (모듈 06) · FR-SCHED · FR-SOLVER

> 실현가능성(영업시간·이동시간·시각 충돌 없음)은 결정론적 솔버가 소유·검증한다. 사용자에게 보이는 시각·순서는 검증값만(환각 시각 금지). 이동시간은 거리 기반 추정, 소요시간은 미표시(거리만)·ADR-0009.

#### US-SCHED-01 — 등록 숙소 기준 날짜별 일정 생성

- **예외**: **Given** 등록 숙소가 없으면 **Then** 생성 버튼을 비활성화하고 안내한다(US-SCHED-11 온램프는 예외). **Given** 지오코딩 실패면 **Then** 지도 지정을 요청하고 생성을 보류한다.

## 에픽 F — 여행 중 일정 재계획 · Plan-B (모듈 07) · FR-PLANB

> 등록 숙소 체크인/아웃은 변경 불가 고정 제약. Plan-B는 숙박 예약을 바꾸지 않고 그날 방문 일정만 재구성한다(ADR-0006). 대안은 솔버 검증 통과분만 노출.

#### US-PLANB-01 — 수동 재계획 요청

- **정상**: **Given** 여행 날짜 구간(시작~종료)에 진입한 상태면 **When** "재계획"으로 사유를 고르면 **Then** 사유를 LLM 해석 입력으로 전달하되 최종 후보는 솔버 검증 결과만 노출한다(등록 숙소 0이어도 여행 구간 안이면 가능).
- 출처: PRD 07-1 · 연관: FR-PLANB-01 · FR-PLANB-02
- 페르소나: 전체 (P3·P4 빈번)

#### US-PLANB-02 — 자동 트리거 선제 제안

- **예외**: **Given** 자동 트리거용 외부 API(날씨/영업시간)가 응답 없으면 **Then** 자동 알림을 띄우지 않고 수동 경로만 유지한다(허위 알림 금지).

#### US-ONTRIP-03 — 다음 예정지 거리·외부 길찾기
**As** 여행자, **I want** 다음 예정지까지 거리를 보고 외부 지도앱으로 길찾기를 잇기를, **so that** 실제 길안내를 받는다.

## 에픽 H — 여행 기록 / 회고 (모듈 09) · FR-RECORD

> plan(계획)·actual(실제)·change-log(변경 이력) 3종 구분 저장(ADR-0013). 모든 생성물은 실패 시 비어 있지 않은 기본 결과 보장.
> **사진 저장 모델(2026-07-12 결정)**: 사진 바이너리는 S3에 일괄 저장하지 않고 **기기 로컬 자산을 참조**해 온디바이스로 표시하며, 서버에는 **메타데이터만**(자산 식별자·촬영 시각·EXIF 위치·연결 장소) 저장한다. **예외 = 커뮤니티 공개 사진만 EXIF 제거 후 S3 업로드**(에픽 K). **멀티 디바이스 미지원** — 기기 변경 시 로컬 사진 유실(메타데이터만 잔존). 회고 카드·요약·SNS 카드(US-REC-06·08·13)는 온디바이스 렌더.

#### US-REC-01 — 방문 완료/취소 체크
**As** 여행자, **I want** 각 장소를 방문 완료/취소로 체크하고 실제 방문 시각을 남기기를, **so that** plan/actual을 구분한다.
- **정상**: **Given** 실행 화면에서 **When** 방문 완료를 체크하면 **Then** 실제(actual) 방문 시각을 기기 시각으로 자동 기록(수정 가능)하고 도착~이동 시각으로 실제 체류 시간을 산출해 계획과 함께 보관한다. 계획에 없던 장소는 '즉석 방문'으로 추가 가능.
- **연계**: **Given** 실제 체류가 계획을 크게 초과해 남은 일정이 밀릴 것으로 예상되면 **Then** Plan-B 트리거로 연결한다.
- 출처: PRD 09-1 · 연관: FR-RECORD-01 · FR-PLANB-01
- 페르소나: 전체

#### US-REC-02 — 사진·메모 첨부 (로컬 참조 · 메타데이터만 서버)
**As** 여행자, **I want** 방문 장소에 사진·메모를 첨부하기를, **so that** 기억을 남긴다.
- **정상**: **Given** 방문 장소가 있으면 **When** 기기 사진을 첨부하면 **Then** 사진 바이너리는 서버에 올리지 않고 **기기 로컬 자산을 참조**해 화면에 표시하며, 서버에는 **메타데이터만**(로컬 자산 식별자·촬영/저장 시각·EXIF 위치[동의 시]·연결 장소) 저장한다. 한 장소에 여러 장·메모를 함께 붙일 수 있다.
- **커뮤니티 공개 경로**: **Given** 사용자가 사진을 커뮤니티 공개에 포함하면 **Then** 그 사진만 EXIF GPS 제거 후 서버(S3)에 업로드해 다른 사용자가 볼 수 있게 한다(에픽 K·FR-COMM-03). 비공개 회고 사진은 업로드하지 않는다.
- **예외**: **Given** 기기 사진 접근 권한이 없거나 원본 자산이 삭제되면 **Then** 침묵 실패 없이 "사진을 불러올 수 없어요"를 표기하되 메모·방문 체크·메타데이터는 사진과 무관하게 저장한다.
- **비고(멀티 디바이스 미지원)**: 로컬 사진은 단일 기기에만 존재 — 기기 변경·재설치 시 사진은 이관되지 않고 메타데이터(방문·장소·시각)만 남는다(Out of Scope).
- 출처: PRD 09-2 · 연관: FR-RECORD-01 · FR-COMM-03
- 페르소나: 전체

# 후속 게이트 에픽 (Q2=C — 에픽 헤더 + 인터페이스 계약만)

> 아래 3모듈은 1차 핵심 여정과 **분리된 출시 게이트**다(ADR-0016). 여기서는 **에픽 목적·스토리 목록(한 줄)·1차 여정과의 인터페이스 계약**만 정의하고, 상세 Given–When–Then 수용기준은 **후속 인셉션**에서 전개한다. (원문 정본: PRD 02·10·11)

## 에픽 J — 앱 전반 AI 어시스턴트 (모듈 02) · FR-ASSIST · *후속*

**목적**: 앱 전반에서 호출되는 대화형 오케스트레이션 계층. 자연어 요청을 해석해 기존 모듈(숙소 탐색·AI 일정 생성·Plan-B·솔버)을 호출·설명·재질의한다. **결정권자가 아니라 통역·중개자** — 실현가능성 결정과 최종 시각·순서는 솔버(모듈 8·10)가 소유(ADR-0015).

**스토리 목록(후속 상세화)**: 1) 호출·컨텍스트 전달(FAB 모달/바텀시트) 2) 대화형 재질의(티키타카) 3) 진행 검토·문제 진단 4) 액션 위임(단독 확정 금지) 5) 대화 이력·세션 6) 가드레일(프롬프트 주입·타 사용자 데이터 비노출) 7) 범위 한계·외부 위임 8) 폴백(LLM·솔버·데이터 실패).

**인터페이스 계약 (1차 여정과의 접점)**:
- 입력: 현재 화면 컨텍스트(현재 여행·등록 숙소·현재 일정 상태·진행 단계·직전 추천). 타 사용자 비공개 데이터·내부 지표는 **컨텍스트 주입 단계 권한 경계로 차단**(프롬프트 주입 무력화).
- 호출: US-STAY-*(탐색), US-SCHED-07(자유 편집·재검증), US-PLANB-*(재계산) 흐름을 **재사용**(신규 계층 생성 없음).
- 출력 규약: 사용자에게 보이는 시각·이동 거리는 **솔버 검증값만**(LLM 임의 수치 금지, 소요시간 미표시). 변경은 명시적 적용 시 솔버 재검증 후 반영·change log 기록.
- 폴백: 실패 시 침묵 없이 재시도/비대화형 기존 흐름으로 연결(ADR-0011).
- 연관: FR-ASSIST-01 · FR-SOLVER-04 · SEC-AUTHZ · SEC-DESIGN(가드레일·rate-limit) · 출처 PRD 02-1~8

## 에픽 K — 여행자 커뮤니티 (모듈 10) · FR-COMMUNITY · *후속*

**목적**: 공개 일정 둘러보기·읽기전용 상세·프로필 조회·'내 여행으로 가져오기'(복제)·좋아요·댓글. 기본 비공개·옵트인, 소셜 그래프(팔로우·구독·스크랩·평판) 없음(ADR-0014).

**스토리 목록(후속 상세화)**: 1) 둘러보기(탐색 랜딩 '여행자 일정') 2) 공개 일정 상세 읽기전용 3) 작성자 프로필 4) 신고·숨김(양방향 차단) 5) 내 일정 공개/공유(마스킹·캡션·해시태그) 6) 가져오기(복제·출처 전파) 7) 내 공유 일정 관리 8) 좋아요(토글·집계) 9) 댓글(평면·본인 삭제·신고).

**인터페이스 계약 (1차 여정과의 접점)**:
- 진입: 탐색 랜딩 '여행자 일정'(US-SHELL-03) — 전용 커뮤니티 탭 없음.
- 상세 뷰: US-SCHED-06(시간표·지도 2뷰)을 **읽기전용 재사용**.
- 공개 게이트: **확정 일정만 공개·복제**(US-SCHED-12 확정 진입과 연결). 기본 비공개, 마스킹(숙소 위치 권역화·절대 날짜 상대화·EXIF 제거)은 게시 전 적용.
- 복제: plan 스냅샷만 독립 복제(actual·GPS·사진·메모·change-log 제외) → US-TRIP-01·US-SCHED-07로 재검증(등록 숙소=출발점 강제 안 함).
- **사진 저장(2026-07-12 결정)**: 회고 사진은 로컬 참조(서버=메타데이터만)이나, **커뮤니티 공개에 포함한 사진만 EXIF GPS 제거 후 S3에 업로드**해 타 사용자에게 제공한다(에픽 H 저장 모델 註·US-REC-02·FR-COMM-03). 공개 해제·삭제 시 업로드 사본 처리 규칙은 후속 상세화.
- **출시 선결 인프라(FR-COMM-02)**: 신고 큐·'검토 중' 노출 보류·금칙어 사전·양방향 차단 — 커뮤니티 출시 전 구현 필수(비고: 조정값은 운영 결정).
- 연관: FR-COMM-01·02·03 · FR-SCHED-12 · SEC-INPUT(금칙어·입력 검증) · SEC-AUTHZ(객체 소유·비로그인 게이트) · 출처 PRD 10-1~9

## 에픽 L — 동행 공동 편집 (모듈 11) · FR-COEDIT · *후속*

**목적**: 한 여행의 소유자가 동행자를 초대해 하나의 일정을 함께 편집(비공개 협업). **MVP = 항목 단위 잠금(soft lock) 교대 편집**(문자 단위 CRDT·여행 중 멀티유저 현장 실행은 후속). 모든 편집은 솔버 재검증·change log(ADR-0016).

**스토리 목록(후속 상세화)**: 1) 동행자 초대(링크/계정·편집자/뷰어) 2) 권한별 동작·변경/회수 3) 항목 단위 잠금 교대 편집·동기화 4) 편집 충돌 해소(침묵 덮어쓰기 금지) 5) 공동 편집도 솔버 재검증 6) 오프라인 편집·재연결 동기화 7) 변경 이력·되돌리기 8) 참여 종료·이탈·소유권 처리.

**인터페이스 계약 (1차 여정과의 접점)**:

- 충돌·이력: 오프라인 충돌은 사용자 선택으로 해소(침묵 실패 금지·ADR-0011), 변경은 change log(ADR-0013)에 통합.
- 커뮤니티 복제와 구분: 본 기능은 **하나의 일정을 함께 고침**(에픽 K '가져오기'는 원본 분리 사본 복제 — 별개).
