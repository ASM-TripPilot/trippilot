# Personas — TripPilot

> **구성 원칙 (Q4=A)**: 페르소나 **4종 = 동행 4축(혼자·커플·친구·가족) × 대표 여행 스타일**. 그 외 취향(예산·페이스·활동·이동·음식)과 진입경로(장소/숙소 우선)·커뮤니티/동행 역할은 각 페르소나의 **속성**으로 병기한다. PRD 동행 유형 6종 중 **부모님·반려동물 동반**은 별도 페르소나 대신 **변형(variant)**으로 흡수한다.
> **근거**: 온보딩 취향 7종(PRD 03) — 여행 스타일·예산·동행·활동·이동·음식·페이스. 진입 이중성(Case A 장소 우선 / Case B 숙소 우선, ADR-0002·0004).
> **범위 주의(Q2=C)**: 커뮤니티(공개자/열람자)·동행(편집자/뷰어) 역할은 후속 게이트 모듈이라 여기서는 각 페르소나의 **성향 속성**으로만 표기하고, 상세 스토리는 후속 인셉션에서 전개한다.

---

## P1 — 혼자 미식 탐험가 (Solo Foodie)

> "혼자서 이 도시의 진짜 맛집·카페를 내 페이스로 훑고 싶다."

| 속성 | 값 |
|---|---|
| 동행 축 | **혼자** |
| 대표 스타일 | **미식** (+ 카페·문화예술) |
| 예산 | 중간 |
| 페이스 | 균형 (하루 3~4곳) |
| 이동 | 대중교통 · 도보 |
| 음식 | 한식 · 일식 · 아시안 |
| 진입 성향 | **장소 우선(Case A)** — 가고 싶은 맛집·카페를 먼저 저장 → 필수 방문지 시드 |
| 커뮤니티 성향 | 열람·복제 활발(다른 여행자 미식 동선 '가져오기'), 공개는 선택적 |
| 동행 편집 성향 | 낮음(주로 단독) |

- **목표**: 검증된 미식 동선을 최소 노력으로 얻고, 현장 변수(휴무·웨이팅)에 유연하게 대응.
- **동기**: 혼자라 결정 피로가 크다 — "골라주되 내가 최종 선택".
- **주요 페인**: 맛집 영업시간·휴무 신선도 낮음, 혼밥 가능 여부 불확실, 동선 낭비.
- **핵심 여정**: 장소 저장(A5) → 여행 생성·필수 방문지(D) → AI 일정 '같이 고르기'(E10) → 현장 방문 체크(G) → 당일 회고·SNS 카드(H).
- **변형**: (반려동물 동반) 반려동물 허용 POI 필터·동선 제약 강조.

## P2 — 커플 휴양러 (Couple Relaxer)

> "둘이 편하게 쉬면서 좋은 숙소를 거점으로 근처만 여유롭게 다니고 싶다."

| 속성 | 값 |
|---|---|
| 동행 축 | **커플** |
| 대표 스타일 | **휴양** (+ 자연·미식) |
| 예산 | 고급 |
| 페이스 | 느긋 (하루 1~2곳) |
| 이동 | 렌터카 · 택시 |
| 음식 | 양식 · 한식 |
| 진입 성향 | **숙소 우선(Case B)** — 좋은 숙소를 먼저 정하고 그 위치 기준으로 동선 |
| 커뮤니티 성향 | 공개·좋아요 중간(감성 동선 공유), 열람 활발 |
| 동행 편집 성향 | **높음** — 파트너와 함께 편집(편집자 1인) |

- **목표**: 숙소 중심의 여유로운 동선 + 기념할 만한 기록.
- **동기**: 이동·방문 수를 늘리기보다 '질' 중심. 숙소가 여행의 축.
- **주요 페인**: 숙소 위치가 동선을 좌우하는데 예약 전엔 감이 안 옴, 둘의 취향 조율.
- **핵심 여정**: 숙소 탐색·등록(C) → 여행 생성·날짜 자동 불러오기(D5) → AI 일정 '완전 AI'(E10) → 동행 공동 편집(L, 후속) → 여행 요약·공유 카드(H13).
- **변형**: (부모님 동반) 접근성·완만한 동선·이른 일정 강조.

## P3 — 친구 액티비티팟 (Friends Activity Crew)

> "친구들과 알차게, 액티비티·핫플을 빡빡하게 돌고 다 같이 일정을 짜고 싶다."

| 속성 | 값 |
|---|---|
| 동행 축 | **친구(그룹)** |
| 대표 스타일 | **액티비티** (+ 쇼핑·야경) |
| 예산 | 중간 |
| 페이스 | 빡빡 (하루 5곳 이상) |
| 이동 | 대중교통 · 도보 |
| 음식 | 한식 · 아시안 · 양식 |
| 진입 성향 | **장소 우선(Case A)** — 다 같이 가고 싶은 핫플을 모아 필수 방문지로 |
| 커뮤니티 성향 | 복제·공개·좋아요·댓글 모두 활발(트렌디 동선 소비·확산) |
| 동행 편집 성향 | **매우 높음** — 여러 편집자 동시 계획, 충돌 해소 빈번 |

- **목표**: 많은 장소를 효율적 동선으로 소화 + 실시간 변수 대응.
- **동기**: 여러 명의 취향을 합의로 모으고, 이동 낭비 없이 알차게.
- **주요 페인**: 다인 취향 충돌, 빡빡한 동선의 이동시간 리스크, 즉흥 변경 잦음.
- **핵심 여정**: 장소 저장(A5) → 동행 초대·공동 편집(L, 후속) → AI 일정 '직접/같이 고르기'(E10) → 여행 중 Plan-B 잦은 재계획(F) → 커뮤니티 공개·좋아요·댓글(K, 후속).

## P4 — 가족(아동) 관광러 (Family Sightseer)

> "아이와 함께 무리 없이, 대표 명소·테마파크를 안전하고 예측 가능하게 다니고 싶다."

| 속성 | 값 |
|---|---|
| 동행 축 | **가족(아동 동반)** |
| 대표 스타일 | **관광** (+ 자연·테마파크) |
| 예산 | 중간~고급 |
| 페이스 | 느긋 (하루 2~3곳) |
| 이동 | 렌터카 |
| 음식 | 한식 · 중식 |
| 진입 성향 | **숙소 우선(Case B)** — 가족 편의 숙소를 거점으로 안정적 동선 |
| 커뮤니티 성향 | 열람·복제 중심(검증된 가족 동선 '가져오기'), 공개는 낮음 |
| 동행 편집 성향 | 중간(배우자와 뷰어/편집자) |

- **목표**: 아이 페이스에 맞는 무리 없는 동선 + 예측 가능성(휴무·대기 최소화).
- **동기**: 실패 없는 여행 — 변수에 약한 가족 여행일수록 실행가능성 보장이 중요.
- **주요 페인**: 아이 체력·화장실·수유실 등 제약, 긴 이동·대기 취약, 휴무 리스크.
- **핵심 여정**: 숙소 탐색·등록(C) → 여행 생성·필수 방문지(D) → AI 일정 '완전 AI', 느긋 페이스(E) → 여행 중 현장 체크(G) → Plan-B(체력·날씨 사유)(F) → 기록/회고(H).
- **변형**: (부모님 동반) 완만·접근성 우선은 P4와 유사, 아동 특수 제약만 제외.
