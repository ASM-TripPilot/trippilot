## 3. 크로스커팅 게이트 (유닛 공통, Phase 0부터)
- **보안(SECURITY-01~15)**: U0에 인증·세션·인가 미들웨어·시크릿·로그 스캐폴딩. 각 유닛 facade에 객체 인가.
- **복원력(RESILIENCY)**: 단일 리전·다중 AZ·아웃박스(at-least-once)·타임아웃·서킷·헬스체크 = U0. RESILIENCY-04·14는 CONSTRUCTION NFR.
- **PBT(Partial 02·03·07·08·09)**: **U2에 집중**(FeasibilityValidator 불변식·직렬화 왕복) + U1(오퍼 정규화)·U3(Place 표준화)·U5(회고 기본 카드 불변식).
- **침묵 실패 금지(ADR-0011)**: 전 유닛 외부 포트에 폴백.

## 4. 순환 검증
- U0→U6 단방향(하위→상위 없음). U6은 이벤트 구독만. 후속 U7~U9는 1차에 단방향 인터페이스 의존. **순환 없음** ✅.
- U2는 어떤 상위 유닛도 동기 호출하지 않음(입력은 커맨드 DTO). Bedrock 교체 시 영향 U2 국한.
