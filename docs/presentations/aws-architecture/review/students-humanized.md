## 슬라이드 7
- TripPilot · Infra 101
- 05 · 요청 하나의 여행
- '일정 만들어 줘'를 누르면 / 생기는 일
- 정문 통과 — 앱의 요청이 인터넷 게이트웨이로 AWS에 들어와요.

- 한 사람이 1초에 10번 넘게 두드리면 잠시 막아요.
- backend(Spring Boot) — 로그인 확인, 여행 정보 조회 같은 본업을 해요.
- ai(FastAPI) — 일정 짜기를 맡아요.
- 취향 판단은 LLM이, 시간·순서 계산은 알고리즘이 해요.
- DB 저장 — 완성된 일정을 PostgreSQL에 넣고 앱으로 돌려줘요.
