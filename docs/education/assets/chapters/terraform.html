같은 저장소에서 DEV에는 NAT Gateway 한 개를, PRD에는 세 개를 만든다. 이 차이를 Terraform이 어떻게 읽고 실제 AWS 리소스로 바꾸는지, TripPilot 브랜치의 코드를 따라가며 배운다.

수업이 끝나면 HCL 블록을 읽고 환경별 변수를 설명하고 provider와 state의 역할을 구분할 수 있다. AWS를 변경하지 않는 검증을 직접 실행하고 Cloudflare DNS 연결에 필요한 추가 설계까지 제시한다.

현재 구현: AWS 추가 학습 예제: Cloudflare v5 학생 실습: AWS 리소스 변경 없음
