잘 동작하는 소스를 배포하는 것과, 검증을 마친 바로 그 이미지를 배포하는 것은 서로 다른 보장이다. 이 강의에서는 현재 브랜치의 실제 배포 절차를 따라가고 같은 이미지를 DEV에서 PRD로 승격하려면 무엇을 더 구현해야 하는지 설계한다.

구간학습 활동시간

30분 과정에서는 선준비된 로컬 클러스터와 성공·실패 로그를 이용하고 digest 확장은 도식과 변경 목록까지만 다룬다. 60분 과정에서는 추가 10분 동안 Helm 이미지 helper 수정안을 렌더링하고 잘못된 digest 입력을 거부하는 테스트를 설계한다.

실습의 실행 범위

이 교재의 작성 과정에서는 AWS 배포를 실행하지 않았다. 수강생은 로컬 검증과 로그 분석을 수행하고 실제 AWS 변경은 강사가 지정한 계정·환경에서만 실행한다. 최초 EKS·NLB·RDS·노드 생성, 인증서 DNS 검증과 이미지 빌드는 한 시간을 넘길 수 있으므로 강사는 계정·도메인·DEV 클러스터를 수업 전에 준비한다. EKS·NAT·RDS·ElastiCache는 실습이 끝나도 비용이 계속 발생한다. 정확한 금액을 고정해 가정하지 말고 강사가 실습 계정의 예산과 종료 절차를 관리한다.
