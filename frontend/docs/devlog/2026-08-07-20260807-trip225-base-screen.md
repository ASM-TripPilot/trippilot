## 후속 티켓 후보 / 다음에 이어서 할 일

1. 날짜 없는 숙소를 고칠 경로 없음 → TRIP-192(e04)에 요구 추가 필요(본문 확인 결과 없음).
2. `해제`가 404를 안 접음(지정의 409 접기와 비대칭) → 별건 티켓 후보.
3. 두 CTA 목적지 동일(`AFTER_WIZARD_ROUTE`) → TRIP-229(g03) 인계.
4. 숙소 검색 화면(e02) 하트 스텁 → 기존 티켓(TRIP-181/182/183) 확인 결과 요구 없음, 추가 필요.
5. 후보 카드 회색 바 3줄 제거 여부 — 지역·가격 BE 요청 철회로 값 영구 미도착, 미채택 대안 승격.
6. 지정 배선 2차 방어선 무심판(참고 등급, 오늘 도달 경로 없음).
7. 부분 채움 차단 규칙 재검토(정본 모순 관측 후속).
