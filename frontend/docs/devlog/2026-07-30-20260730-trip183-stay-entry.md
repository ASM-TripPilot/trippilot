- **⚠️ 서브 에이전트 미사용(하네스 이탈)** — 세션 상위 지침이 "요청 없이 Agent 도구 금지"라 오케가 전 단계 직접 수행. 3-a 맹점 훑기·3-b 인터뷰는 사용자 응답이 입력이라 생략하고, 열린 질문 10건을 **판정 + 근거**로 브리프 §7에 남겼다.

## 예상과 달랐던 것

1. **Figma에 '내 주변' 진입점이 없다**(밴드 e 프레임 전수 실측). 티켓의 "밴드 미확인"이 추정이 아니라 **공백**으로 확정됐다. 대신 `i21-[폴백] 위치 권한 거부 · 통합`(1790:3549)에 *"현재 위치 대신 등록 숙소를 기준으로 잡았어요"*가 있었다 — **문구만 차용**하고 지도·핀 UI는 밴드 i 몫으로 두었다.
2. **d1b와 e00을 나란히 대조하니 BR-U1-07이 실측으로 확인됐다.** 지역 6개·레이아웃·사진이 완전히 같고 차이는 카피 5줄 + 카드 부제뿐. 그대로 `COPY` 상수 표가 됐다.
3. **US-EXPL-02 예외항이 집계 공백의 답을 미리 갖고 있었다** — *"집계를 못 불러오면 카드는 유지하고 집계 값만 생략한다"*. 없는 것을 만들지 않고 규칙대로 생략.
4. **`typedRoutes: true`가 범위를 밀어 올렸다.** 목적지 파일이 없으면 `router.push('/explore/destination/…')`가 타입에서 막혀 BR-U1-07 분기를 구현할 수 없다 → 밴드 d 자리에 **경로만**(12줄) 만들었다. 경계를 넘은 것이므로 원장에 명시.
5. **MSW `server.listen()` 누락 시 "빈 배열 케이스만 통과"** — 빈 배열도 `unavailable`로 접히니 기대와 우연히 일치했다. **통과가 곧 검증은 아니라는 실물 사례.**

## 설계 결정

- **지역 목록 = 프론트 상수 6개**, `code`(ASCII, testID용)와 `name`(한글, 서버 질의값 겸 라벨)을 분리.
- **`resolveNearby` = 의존성 주입 순수 함수.** 우선순위 현재 위치 > 등록 숙소 > 없음. 어떤 경로에서도 예외를 밖으로 안 낸다(INV-4). 권한 거부와 측위 실패를 다른 `reason`으로 구분 — 사용자가 할 일이 다르다.
- **좌표를 못 구하면 이동하지 않는다.** `coordConfirmed=false`인 등록 숙소는 건너뛴다(INV-U1-08).
- **`radiusKm`을 안 보낸다** — 반경 정책은 서버 기본값(TRIP-202)이 갖는다.
- **`purpose='trip'`은 컴포넌트·카피·테스트만.** d1b 진입 동선은 밴드 d 티켓 몫(범위 누수 방지).

## 알려진 한계 (숨기지 않음)

1. **대체 고지가 e02로 안 이어진다** — `fallback`이면 이 화면에 문구를 세팅하고 곧바로 이동하므로 결과 화면에선 평범한 목록이 보인다. e02에 파라미터+배너를 더해야 하는데 이 칸 밖 → **후속 티켓 후보**.

## 하네스 규칙 후보
