## 플로우 다이어그램 요약 (개별 화면이 아닌 전체 흐름도)

- **FLOW·a** — 온보딩: 스플래시 → 소셜 로그인(실패/중복/취소 분기) → 약관 동의 → 위치 권한(거부/허용 분기) → 취향 설정 단계들이 순차 연결.
- **FLOW·b** — 숙소 탐색: 검색(로딩/실패/결과없음/필터0건 분기) → 선택 또는 직접 등록(OTA 예약/취소 분기), 권역 역추천(충돌/지도오류 분기) 포함.
- **FLOW·c** — 여행 생성·거점: 여행 생성 → 기준 거점 지정(충돌/공백/직전 숙소 기준/미등록 분기).
- **FLOW·d** — AI 일정 생성: 일정 설정 → "완전 AI"(전체 자동) / "같이"(협업) 경로로 분기, 후보 선택·슬롯 고르기를 거쳐 "이대로 완성"으로 수렴. (전체 세트 중 가장 큰 다이어그램)
- **FLOW·e** — 활성 일정·현장 이용: 뷰 전환/실제 경로/장소 도착 후 대안 찾기·완료·같이 고르기·AI 위임·직접 수정·수동 입력 등 재계획 분기, "여행 계속하기"로 순환.
- **FLOW·f** — 기록·회고: 오프라인/오류 분기, 계획 vs 실제 비교, 오늘의 회고, 수동 기록, 사진 없음 케이스 연결.
- **FLOW·g** — 설정·알림: 알림 설정(없음/권한거부 분기), 동의 철회·취소 분기. g07 제휴 고지 모달이 b03 예약하기에서 진입됨을 명시.
- **FLOW·h** — 홈 대시보드 아웃링크: 홈 → b(숙소 탐색), d·e(일정 보기), c(여행 만들기), b07(권역 추천), b05(위시리스트)로 연결되는 화살표.
- **flowSM_seg / flowSM_seg-1** — 실질적 내용 없는 빈 커넥터 조각(1px 높이).
- **여행 중 확인 / 예외·폴백 / 재계획 트리거 / 재계획 — 결과·대안 / 재계획 — 사유·분기 / 현장 이용 / 확정·반영** — FLOW·e 다이어그램 구간을 나누는 텍스트 소제목 라벨.
- **Rectangle** — 9×9px 크기의 작은 UI 아이콘/장식용 도형 자산 (화면 아님).
