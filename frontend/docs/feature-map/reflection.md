# 하루 회고 (j03)

여행 하루의 회고 화면이다. 그 날 회고 레코드가 없고 날짜가 오늘(서울) 이하이면 화면을 여는 순간 서버에 초안 생성을 한 번 요청하고, 도착하면 방문·이동·사진 통계, 서버(AI 또는 규칙) 서술, AI 장면, 이 기기 앨범의 사진, 기분·한 줄 메모를 보여 준다. 사용자는 서술을 직접 고쳐 쓰거나(초안은 서버에 남는다), 활동이 없는 날에도 직접 회고를 작성할 수 있다. 일차 칩으로 같은 여행의 다른 날로 옮기고, 하단 바로 방문 기록·요약과 오간다.

## Sub-features

- `rf-auto-create` 레코드가 없고 날짜 ≤ 오늘이면 마운트당 1회 생성 POST. 도착 전까지 `회고를 준비하고 있어요`.
- `rf-pending` 조회 중·생성 중 얼굴 `회고를 준비하고 있어요` / `잠시만 기다려 주세요`.
- `rf-default` 방문 2곳 이상·사진 1장 이상: 통계(`방문`·`이동`·`사진`), `오늘의 기록` 서술 카드 + `수정`, AI 장면, 사진 격자, 기분·한 줄 메모.
- `rf-insufficient` 방문 < 2 또는 사진 0: 통계(방문 < 2 면 이동 `—`), 지도 자리 안내(사유 3종), 서술, 장면, 사진 없음이면 `사진 없음`, 기분·한 줄 메모.
- `rf-map-notice` 지도 자리 사유: 방문 < 2 → `동선 없음`/`방문 기록이 2곳 미만이에요`, 위치 권한 거부 → `위치 권한 꺼짐`, 그 외 → `동선 지도 없음`/`실제 이동 경로 지도는 아직 지원하지 않아요`.
- `rf-empty` 방문 0·사진 0이고 직접 쓴 수정본이 없으면 `오늘 기록된 활동이 없습니다`(오늘이 아니면 `이 날 기록된 활동이 없습니다`) + 하단 `직접 회고 작성`. 미래 날짜도 생성 없이 이 얼굴.
- `rf-error` 조회 실패 또는 생성 실패: 통계 + `회고를 불러오지 못했어요` / `직접 회고를 작성할 수 있어요` + `다시 시도`(생성 실패면 POST 재발사, 조회 실패면 재조회) + 하단 `직접 회고 작성`.
- `rf-edit` 헤더 `편집`·서술 `수정`·`직접 회고 작성` 으로 편집 모드: 여러 줄 입력(`직접 회고를 작성해 보세요`, 최대 4000자) + `취소`·`저장`. 빈 글·서버 안내문 그대로면 `저장` 비활성. 실패면 `저장하지 못했어요. 다시 시도해 주세요`.
- `rf-ai-draft` 서버 표시본(수정본 우선, 없으면 초안) → 결측이면 `방문 N곳 · 이동 Nkm · 사진 N장의 하루였어요.` 로 폴백. 미치환 템플릿(`{region} …`)은 그날 지역·날짜로 채우고, 템플릿뿐이면 통계 문장으로 바꾼다.
- `rf-mood` 기분 칩 `아쉬워요`·`괜찮았어요`·`좋았어요` — 누르면 즉시 저장, 선택된 칩을 다시 누르면 지운다.
- `rf-short-memo` 한 줄 메모(`오늘 하루를 한 줄로 남겨보세요`, 글자 수 표시) — 입력을 마치면 바뀐 경우에만 저장, 성공 토스트 `한 줄 메모를 저장했어요`. 실패면 `저장하지 못했어요. 다시 시도해 주세요`.
- `rf-day-tabs` 여행 기간 일차 칩(`N일차`, 오늘 칩은 `오늘 · N일차`). 미래 일차 칩은 비활성. 누르면 같은 화면이 그 날짜로 교체된다(스택에 안 쌓인다).
- `rf-title` 헤더 제목: 보는 날이 오늘이면 `오늘의 회고`, 아니면 `하루 회고`.
- `rf-photos` 사진은 서버 URL 이 아니라 그 날 방문 사진 메타를 이 기기 앨범에서 찾아 그린다(다른 기기·못 찾은 사진은 조용히 뺀다).
- `rf-bar` 하단 바: `기록`(그 날짜 `?day=` 로 j01)·`요약`(서버 요약 ready 일 때만)·뒤로. 편집 중엔 바가 숨는다.

## How to get to it (user POV)

- j01 방문 기록 하단 바 `회고` 칸(선택한 일차, 미래 일차면 비활성) (`trip-record`).
- j04 요약의 `N일차 회고` 칩, 또는 j04 하단 바 `회고` 칸(여행 중이면 오늘, 끝났으면 마지막 일차).
- j03 안의 일차 칩(같은 라우트를 날짜만 바꿔 교체).
- 알림함 행·푸시 탭: 종류 `REFLECTION_DAILY`(payload 에 `dayDate` 가 있어야 이동).
- 도우미 다음 행동 `OPEN_REFLECTION`(날짜 있음).
- 딥링크 `trippilot://trips/<tripId>/records/reflection/<YYYY-MM-DD>`. 시뮬레이터에선 `com.trippilot.travel://` 스킴으로 연다.

## Driving it with agent-device

Preconditions:

- 시작일이 오늘 이하인 여행. 얼굴별 데이터:
  - `rf-default`: 그 날 방문 완료 2곳 이상 + 사진 1장 이상(j01 에서 만든다, 사진은 **이 시뮬레이터 앨범**에서 붙여야 격자에 보인다).
  - `rf-insufficient`: 방문 1곳만, 또는 방문 2곳 이상인데 사진 0장.
  - `rf-empty`: 방문·사진 0인 지난/오늘 날짜, 또는 미래 일차(딥링크로 직접 연다 — 칩은 비활성).
  - `rf-error`(생성 실패): 레코드 없는 날을 네트워크를 끊은 채 연다. 조회 실패: 회고 목록 조회 전에 끊는다.
  - 지도 사유 `permission`: 방문 2곳 이상 + 시뮬레이터 위치 권한 `안 함`.
- 서버 AI 가 미개통·실패면 서술은 규칙/기본 문장이다 — `source` 로 화면이 갈리지 않으므로 서술 문구 자체를 AI 여부의 증거로 쓰지 않는다.
- 조작 절차·셀렉터 함정은 `trippilot-sim-qa` 스킬 §2·§4.

- **자동 생성.** 레코드 없는 오늘 날짜로 j01 하단 바 testID: `record-trip-bottom-bar{-tab-reflection}` 을 누른다. 먼저 testID: `reflection-daily-pending`(`회고를 준비하고 있어요`)이 보이고, 생성 응답 뒤 통계 testID: `reflection-daily-stats`(`방문`·`이동`·`사진`)가 나타난다. 빈 얼굴이 중간에 비치지 않아야 한다.
- **기본 얼굴.** 서술 카드 `오늘의 기록` 의 본문 testID: `reflection-daily-narrative`, AI 장면이 있으면 testID: `reflection-daily-scenes`, 사진 격자 testID: `reflection-daily-photo-grid`, 기분·메모 블록 testID: `reflection-daily-extras`(`오늘 어땠어요?`)가 보인다. 이 얼굴엔 지도 자리 안내가 없다.
- **부족 얼굴.** 방문 1곳 날짜를 연다. 통계 `이동` 이 `—` 이고, 지도 자리 testID: `reflection-daily-map-notice` 안에 `동선 없음` 과 testID: `reflection-daily-map-notice-reason-{few-visits}`(`방문 기록이 2곳 미만이에요`). 사진 0이면 testID: `reflection-daily-photo-empty`(`사진 없음`). 위치 권한을 끄고 방문 2곳 날을 열면 사유 testID 가 `reflection-daily-map-notice-reason-{permission}`, 권한 허용·미결정이면 `reflection-daily-map-notice-reason-{no-route}`.
- **빈 얼굴.** 활동 없는 날짜를 연다. testID: `reflection-daily-empty`(`오늘 기록된 활동이 없습니다` 또는 `이 날 기록된 활동이 없습니다`)와 하단 testID: `reflection-daily-compose`(`직접 회고 작성`).
- **오류 얼굴·재시도.** 네트워크를 끊고 레코드 없는 날짜를 연다. testID: `reflection-daily-error`(`회고를 불러오지 못했어요`) → 네트워크 복구 → testID: `reflection-daily-retry`(`다시 시도`)를 누르면 pending 을 거쳐 통계가 뜬다. 자동 재시도는 없다.
- **직접 작성(빈·오류 얼굴).** testID: `reflection-daily-compose` → 입력 testID: `reflection-daily-edit-input`(`직접 회고를 작성해 보세요`)에 글을 `fill` → testID: `reflection-daily-edit-save`(`저장`). 편집이 닫히고 빈 얼굴이 아니라 쓴 글이 서술로 보인다(수정본이 있으면 활동 0이어도 빈 얼굴이 아니다).
- **AI 초안 편집.** 기본 얼굴에서 testID: `reflection-daily-narrative-edit`(`수정`) 또는 헤더 testID: `reflection-daily-edit`(`편집`)를 누른다. 입력에 현재 서술이 채워져 있다(서버 안내문 `이 날은 기록된 방문이 없어요. 다녀온 곳을 남기면 회고가 채워져요.` 는 빈칸으로). 고쳐 저장하면 서술이 바뀐다. testID: `reflection-daily-edit-cancel`(`취소`)은 바꾸지 않고 닫는다.
- **저장 비활성·실패.** 입력을 비우면 `reflection-daily-edit-save` 가 비활성(`disabled`)이다. 저장 직전 네트워크를 끊으면 편집이 열린 채 `저장하지 못했어요. 다시 시도해 주세요`.
- **기분.** testID: `reflection-daily-mood-{code}`(code=`good`)(`좋았어요`)을 누르면 `selected` 가 참이 된다. 다시 누르면 거짓(지워짐). 다른 화면을 갔다 와도 선택이 남는지 본다.
- **한 줄 메모.** testID: `reflection-daily-memo-input` 에 글을 넣고 입력을 마친다(키보드 내림). 토스트 testID: `reflection-daily-memo-saved-toast`(`한 줄 메모를 저장했어요`). 같은 글로 다시 마치면 토스트가 다시 뜨지 않는다.
- **일차 칩.** testID: `reflection-daily-day-tab-{N}`(N=1) 을 누르면 같은 화면이 1일차 날짜로 바뀌고 그 칩이 `selected` 다. 오늘 칩 라벨은 `오늘 · N일차`. 미래 일차 칩은 비활성이라 눌러도 안 바뀐다. 칩을 여러 번 오가도 하단 바 뒤로 한 번에 들어온 곳으로 나간다(교체라 쌓이지 않는다).
- **하단 바.** testID: `reflection-daily-bottom-bar{-tab-records}`(`기록`)를 누르면 j01 이 그 날짜 일차로 열린다. testID: `reflection-daily-bottom-bar{-tab-summary}`(`요약`)는 요약 ready 전엔 비활성. testID: `reflection-daily-bottom-bar{-back}` 은 탭에서 왔으면 기록 탭, 알림함·도우미에서 왔으면 그 화면으로 돌아간다. 편집 중엔 바가 없다.
- **알림함 진입.** 알림함에서 회고 알림 행 testID: `notification-inbox-row` 을 누르면 그 날짜 j03 이 열리고, 뒤로 원이 알림함으로 돌아간다.
- **교차 확인.** j01 에서 방문을 하나 더 완료한 뒤 j03 을 다시 열어 통계 `방문` 이 늘었는지 본다(같은 세션 캐시만으로 바뀌지 않으면 서버 재집계 시점 문제로 따로 적는다).

## Gotchas

- 생성 POST 는 마운트당 1회다. 방문을 추가한 뒤 이미 레코드가 있는 날은 다시 만들지 않는다 — 통계가 j01 과 다르면 서버 집계 시점 문제다(과거 QA 113). 화면을 닫았다 여는 것으로는 재생성되지 않는다.
- 사진 격자는 이 기기 앨범 사진만 그린다. 서버 통계 `사진` 이 1 이상이어도 다른 기기 사진이면 격자 칸이 비어 있다(안내 없음) — 사진 검증은 같은 시뮬레이터에서 붙인 사진으로만 한다.
- 지도는 회고 계약에 좌표가 없어 기본 얼굴에선 그리지 않고, 부족 얼굴에선 늘 안내 박스다. 지도가 안 보이는 것은 정상이다.
- 위치 권한은 조회만 하고 묻지 않는다. 미결정(`undetermined`)은 "모름"이라 사유가 `no-route` 로 나온다 — `permission` 사유를 보려면 명시적으로 거부해야 한다.
- 편집 입력·한 줄 입력은 키보드 회피 컨테이너 안이다. 키보드가 `저장`·`취소` 를 가리는지, 키보드가 뜬 채 첫 탭이 버튼으로 가는지는 실화면으로만 확인된다(과거 QA R2-05·R2-06). **[실화면 전용]**
- j03 은 iOS 가장자리 스와이프 뒤로가 꺼져 있다. 뒤로는 하단 바 뒤로 원뿐이고, 편집 중엔 바가 숨으니 `취소` 로 먼저 나온다.
- 푸시·홈 등 탭 바로 위에서 j03 을 연 뒤 일차 칩을 누르면 바 입장 모프가 칩마다 다시 돈다(traps-reflection.md, 처방 전). 모프 중 `-start-{탭}` 복제 칸은 눌리지 않는다.
- 헤더 `편집` 은 조회 중·빈·오류 얼굴에서도 보인다. 조회 중에 편집으로 들어가면 시드가 빈 글이다 — 편집 검증은 얼굴이 정해진 뒤 한다.
- 미치환 템플릿(`{region} · {start_date}~{end_date}`)이 그대로 보이면 결함이다 — 지금은 그날 지역·날짜로 채우거나 통계 문장으로 바꾼다.
- 푸시(`REFLECTION_DAILY`)는 개발 서버에서 발송이 꺼져 있을 수 있다(확인 필요). 알림함 행 경로와 푸시 탭 경로를 따로 검증한다.
- 알림 payload 에 `dayDate` 가 없으면 행을 눌러도 이동하지 않는다(정상 — 목적지 없음).
- testID 표기: `a-{x}` 는 `a-` 뒤에 실행 값 x 가 붙은 것이고, `a{-b}` 는 실제 testID `a-b` 다(하단 바·헤더·행 카드). 접근성 트리에서는 합친 값으로 찾는다.
- [실화면] 2026-10-31 자동 생성은 pending(`회고를 준비하고 있어요`/`잠시만 기다려 주세요`)이 10~15초 보인 뒤 통계로 바뀌었다(중간에 빈 얼굴 없음). 일차 칩으로 레코드 없는 날로 옮겨도 같은 pending → 생성이 돌았다.
