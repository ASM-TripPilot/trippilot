# 기능 안내 6장

온보딩을 막 마친 사용자에게 앱의 큰 기능 여섯 가지를 한 장씩 보여 주는 가로 넘김 안내다(담기 → 숙소 → 일정 짜기 → 여행 중 → 기록 → ✦ 도우미). 각 장에는 움직이는 무대 그림과 제목·본문이 있고, `다음` 이나 옆으로 밀기로 넘긴다. 1~5장은 `건너뛰기`, 6장은 `시작하기` 로 홈에 들어가며, 안내는 스택에 남지 않는다.

## Sub-features

- `tour-pages` 6장 고정 카피(제목·본문)와 무대 모션.
- `tour-next` 하단 `다음` → 다음 장(1~5장).
- `tour-swipe` 가로 페이징 스와이프로 장 이동, 진행 점이 현재 장을 따른다.
- `tour-skip` 상단 `건너뛰기`(1~5장) → 홈 탭으로 교체.
- `tour-start` 6장에서 `건너뛰기` 가 사라지고 하단이 `시작하기` 로 바뀐다 → 홈 탭으로 교체.
- `tour-no-back` iOS 스와이프 뒤로가 꺼져 있다. Android 하드웨어 뒤로는 이전 장(1장에선 무시).
- `tour-reduce-motion` 기기 "동작 줄이기"가 켜져 있으면 모션 없이 끝 프레임을 보인다.

## How to get to it (user POV)

- 온보딩 취향 2/2 `완료` → 기능 안내 1장(`onboarding` 기능 파일).
- 온보딩 취향 2/2 `나중에 설정하고 시작` → 기능 안내 1장.
- 온보딩 취향 1/2 `나중에 설정하고 시작` → 기능 안내 1장.
- 그 밖의 진입(설정 메뉴 등)은 없다. 홈 계정은 딥링크 `trippilot:///onboarding-tour`(시뮬 `com.trippilot.travel://onboarding-tour`)로 연다 — 1장부터 뜬다(2026-10-31 실측).
- 개발 프리뷰(정적): `trippilot://_dev/preview?state=onboarding-tour-1` … `onboarding-tour-6`(키마다 앱 재기동).

## Driving it with agent-device

Preconditions:

- 신규 계정이 온보딩 취향 단계에 와 있다(`onboarding`). 이 진입은 계정당 한 번이다 — 놓치면 딥링크(확인 필요) 또는 프리뷰로만 다시 본다. 프리뷰로 본 것은 실화면 진입 검증으로 치지 않는다.

- **1장 도착.** 취향 2/2 `완료` 를 누른다. testID: `onboarding-tour-page-1` 과 testID: `onboarding-tour-title-1`(`가고 싶은 곳을` / `하트로 담아요`), testID: `onboarding-tour-body-1`, 진행 점 testID: `onboarding-tour-progress`(라벨 `기능 안내 진행`, 값은 iOS 트리에서 퍼센트로 나온다 — 1장 20%·2장 40%…6장 120%, 아래 결함 의심), 상단 testID: `onboarding-tour-skip`(`건너뛰기`), 하단 testID: `onboarding-tour-next`(`다음`)가 보인다
- **다음.** testID: `onboarding-tour-next` 를 누른다. 2장 제목 `숙소는 여기서 고르고,` / `예약은 제휴 사이트에서` 가 보이고 진행 값이 2 가 된다
- **스와이프.** testID: `onboarding-tour-pager` 위에서 오른쪽→왼쪽으로 민다. 3장 `일정은 원하는` / `방식으로 짜요`, 4장 `여행 중엔` / `앱을 덜 열어도 돼요`, 5장 `다녀온 여행은` / `한 장으로 남아요` 로 넘어가며 진행 값이 따라간다
- **6장.** 6장(`막히면 ✦ 도우미에게` / `물어보세요`)에 오면 `건너뛰기` 가 사라지고 하단이 testID: `onboarding-tour-start`(`시작하기`)로 바뀐다
- **시작하기.** testID: `onboarding-tour-start` 를 누른다. 홈 탭이 뜬다. 다른 화면 확인: 앱을 재시작해도 기능 안내나 온보딩이 다시 뜨지 않는다
- **건너뛰기.** (다른 신규 계정에서) 1~5장 중 testID: `onboarding-tour-skip` 을 누른다. 홈 탭이 바로 뜬다
- **뒤로 막힘.** 안내 화면 왼쪽 가장자리에서 오른쪽으로 민다. 온보딩으로 돌아가지 않는다
- **연타.** 1장 도착 직후(취향 `완료` 연타 포함) 하단을 빠르게 두 번 누른다. 1장이 실제로 보였다가 2장으로 한 장만 넘어가야 한다
- **증거.** 각 장 도착 시 스크린샷 1장씩(모션 끝난 뒤 1~2초 쉬고).

## Gotchas

- **[실화면 전용]** 페이징 스냅·스와이프, 무대 모션(경로가 그려지는 애니메이션) 재생·클립 모양, 동작 줄이기 ON 첫 프레임 빈 무대, 안전영역, `✦` 글리프 폰트 대체, `시작하기` 직후 홈 번쩍임은 실화면으로만 확인된다.
- 무대 위 그림은 터치를 받지 않는다(`pointerEvents="none"`). 무대 그림 속 요소(하트·핀 등)를 누르려 하지 않는다 — 실제 터치 차단 여부도 실화면 전용이다.
- 이동 목적지는 `'/(tabs)'` 다. `건너뛰기`·`시작하기` 가 무반응이면 `'/'` 함정 회귀다(TRIP-1597 전례).
- 스와이프 직후에는 진행 값이 정지(모멘텀 끝) 뒤에 바뀐다 — 손을 떼자마자 읽지 않는다.
- 온보딩을 거친 이 마운트에서는 기존 계정용 권한 안내 카드(`permissions`)가 뜨지 않는다. 기능 안내 뒤 홈으로 바로 가는 것이 정상이다.
- 이 화면은 홈 가드 안에 있다 — 로그아웃·401 이면 가드가 치운다.
- [실화면] 2026-10-31 주 경로(온보딩 취향 완료) 도달 불가 — 신규 계정 없음. 대신 딥링크로 6장·`다음`·스와이프·`건너뛰기`(5장 → 홈, 스택에 안 남음)·`시작하기`(6장 → 홈)를 확인했다. 왼쪽 가장자리 끌기는 이전 장으로 넘어갈 뿐 안내를 떠나지 않는다(`tour-no-back` 만족). `tour-reduce-motion` 미확인.
- [실화면] 2026-10-31 [결함 의심 FM-L6-03] (low, 접근성) 진행 표시 값이 1장 20% → 6장 **120%** 로 읽힌다 — `accessibilityValue={{min:1,max:6,now:page}}` 를 iOS 가 now/(max−min) 로 환산하는 것으로 보인다. VoiceOver 가 "120퍼센트"를 읽는다. 증거 `feature-tour/06-page6.png`.
