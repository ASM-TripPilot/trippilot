# CLAUDE.md — frontend 개발 하네스

This file provides guidance to Claude Code (claude.ai/code) when working in `frontend/`.

> **위치·범위**: 프로젝트 전반 가이드(리포 구조·정본 문서·아키텍처·빌드/테스트·컨벤션)는 **리포 루트 `CLAUDE.md`**에 있다 — Claude Code를 frontend/에서 실행하면 상위 디렉토리 CLAUDE.md로 함께 자동 로드된다. 이 파일은 **frontend 개발 하네스 규칙만** 담는다.

## 하네스: TripPilot 개발 사이클

**목표:** 루프 엔지니어링 기반 TDD 개발 사이클(인지→메모리→설계→테스트→구현→검증→리팩토링→기록)을 사용자 검토 게이트 2개(테스트 승인·구현 승인)와 함께 운영한다.

**트리거:** TripPilot **frontend** 코드 변경 작업(기능/화면/티켓/버그/리팩토링/스캐폴딩) 요청 시 `trippilot-dev-cycle` 스킬을 사용하라(하네스 소재: `frontend/.claude/`). backend/ai 코드 작업용 하네스는 아직 없다 — 해당 요청 시 하네스 부재를 알리고 일반 워크플로우로 진행하라. 단순 질문·문서 열람·문서 편집은 직접 응답 가능(단, 의미 있는 문서 변경은 옵시디언 개발일지에 기록).

**장치 판정 규칙(졸업 조건):** 하네스에 검사·장치를 **추가할 때는 유지 판정 조건을 함께 적는다** — 무엇을 몇 사이클 세고, 어떤 결과면 떼어내거나 조건부로 격하하는지. 조건 없이 추가한 장치는 단조증가하고, 아무도 그 효용을 세지 않는다. 실제로 해시 대조와 red 소급이 **12사이클 0건**인 것을 세고 있던 사람이 없었다. 판정에 쓸 실적은 scribe가 개발로그에 남긴다.

**규칙 본문 편집 규칙(2026-07-23 신설):** 규칙 문서(`frontend/.claude/**`)에는 **규칙과 기제까지만 쓴다.** 기제는 *왜 그래야 하는가*를 시점과 무관하게 설명하는 것이라 규칙의 일부다(빼면 경계 사례에서 적용 판단을 못 한다). **사건 식별자 — 사이클 ID·날짜·"몇 건이었다" — 는 옵시디언 `하네스 변경이력.md` 소관이고, 본문에는 `(실측 n건, 상세는 하네스 변경이력)` 한 조각만 남긴다.** 서사가 준수율을 올리는 효과는 실재하므로 통째로 빼지는 않되, 한 문단이 사건 재연에 3문장을 쓰고 있으면 압축 대상이다. **전수 스윕은 하지 않는다** — 그 문단을 다른 이유로 만질 때 함께 적용해 점진 수렴시킨다(잘 도는 문서를 통째로 흔드는 비용이 이득보다 크다).

> ⚠️ **순서가 규칙의 절반이다 — 원장 확인이 먼저다.** 본문에서 사건을 빼기 전에 **그 사건이 `하네스 변경이력.md`에 실제로 있는지 grep한다.** 없으면 소급 기록 행을 먼저 append하고, 그다음에 본문을 압축한다. 첫 적용에서 실제로 걸렸다 — `20260719-trip161-preview` 소실 사건은 **SKILL.md 본문이 유일한 기록**이었고, 확인 없이 압축했다면 그대로 소실이었다. "원장 소관이니 본문에선 뺀다"는 원장에 있을 때만 참이다. *유지 판정: 6사이클 관찰 — 이 규칙을 적용한 문단이 0건이면(= 만질 일이 없었다는 뜻) 규칙을 떼고 필요할 때 그때 판단한다.*

**모델 배치:** 자리별 모델의 정본은 **각 에이전트 frontmatter**다(`frontend/.claude/agents/*.md`). 사이클 SKILL은 예외 한 자리(4-b)만 명시하고 나머지는 frontmatter에 맡긴다 — 배치를 두 군데 적으면 갈라진다. ⚠️ **메타 스킬 `harness:harness`의 "모든 에이전트는 `model: "opus"`" 지침보다 현재 frontmatter가 우선한다.** 하네스 정비 중 그 스킬이 로드돼도 일괄 opus로 되돌리지 마라 — 현 배치는 12사이클 실측(자리별 실패 가시성·되돌리기 비용·호출 빈도) 위에 있고, 근거·원칙·관찰 상태는 변경이력에 있다.

**변경 이력:** 원장은 옵시디언 `TripPilot/하네스 변경이력.md`다 — 하네스(에이전트·스킬·settings·이 파일)를 변경하면 반드시 그 표에 행을 추가하라(append-only, 날짜·변경 내용·대상·사유). 리포 쪽 diff는 git 히스토리(`frontend/.claude/`)로 추적한다.
