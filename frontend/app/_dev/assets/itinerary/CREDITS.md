# 이미지 출처 (app/_dev/assets/itinerary)

**개발 프리뷰 전용 의도다.** `app/_dev/preview.tsx` 의 h11(AI 추천안 초안) 픽스처가
카드 썸네일 자리를 채우는 데만 쓴다 — 프로덕션 화면은 서버가 준 `imageUrl` 만 그린다.

**그 의도는 빌드가 막는다(TRIP-1347).** `_dev/preview` 는 expo-router 라우트이고 expo-router 는
`_` 접두 경로를 라우트에서 제외하지 않지만(제외 대상은 `+api`·`+html`·`+middleware` 뿐),
`metro.config.js` 가 `NODE_ENV=production` 에서 `app/_dev` 를 blockList 로 제외한다. 그래서 운영
번들에는 이 화면도, `require` 된 세 파일도 실리지 않고 개발 번들에만 들어간다
(`pnpm bundle:report` 가 CI 에서 소스맵에 `app/_dev` 0건을 단언 — TRIP-1612).

## 알아야 할 것

- 세 장 모두 **디자이너가 Figma 목업에 넣은 사진**을 내려받은 것이다(2026-08-10, TRIP-339).
  원저작자와 이용 조건을 확인하지 못했다.
- 그래서 **프로덕션 화면에서는 import 하지 않는다.** 프리뷰를 Figma 와 눈으로 대조할 때
  사진 칸이 통째로 비어 있으면 대조 자체가 불가능해서 들인 값이다.
- **라이선스는 여전히 미확인이다**: 운영 번들에는 안 실리지만 리포 에셋이라, 라이선스가 분명한
  사진으로 갈아치우거나 `_dev` 제외가 풀리는 일이 없는지 계속 확인해야 한다.
- 원본은 800~1280px 였다. 표시 크기가 78×78 이라 긴 변 480px 로 줄여 넣었다.
