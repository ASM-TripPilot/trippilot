# `src/features/trip/` — 여행 생성 위저드(g01·g02)의 계약·판정·화면

서버 계약(orval `trips`·`preferences`·`bases`)을 도메인 이름으로 감싸는 얇은 훅, 위저드 드래프트 상태(Zustand), 순수 판정·파생, 무상태 화면·편집 시트. 판정과 렌더를 파일로 가른다 — 순수 계산(`tripWizardStep1.ts`·`tripSummary.ts` 등)·상태 상자(`tripWizardStore.ts`)·무상태 화면·시트. `validateTripDraft`를 부르는 곳은 배선 층(`pages/trip-new-step1/`) 하나뿐이고, 화면이 서버 훅을 직접 물지 않는 것은 `tripWizardStep1Boundary.test.ts`가 소스 스캔으로 강제한다. 날짜 산술은 epoch-day 방식이고 `new Date(` 생성자를 쓰지 않는다(경계 테스트가 그 리터럴을 금지). 편집 시트는 전부 `@gorhom/bottom-sheet` 기반 props-only 무상태이고, 개폐·드래프트는 배선이 소유하며 시트는 화면의 형제로 마운트된다 — 실개폐·딤·터치차단은 통과형 목이라 jest 사각(6-b 전용).
