# `src/features/trip/` — 여행 생성 위저드(g01·g02)의 계약·판정·시트

서버 계약(orval `trips`·`preferences`·`bases`)을 도메인 이름으로 감싸는 얇은 훅, 위저드 드래프트 상태(Zustand), 순수 판정·파생, 무상태 편집 시트·확인 다이얼로그. 판정과 렌더를 파일로 가른다 — 순수 계산(`tripWizardStep1.ts`·`tripSummary.ts` 등)·상태 상자(`tripWizardStore.ts`)·시트·다이얼로그. 위저드 화면 뷰 두 개(`TripWizardStep1Screen`·`TripWizardStep2Screen`)는 TRIP-1149로 각 page 슬라이스(`pages/trip-new-step1`·`pages/trip-new-step2`)로 이사했다 — 행은 `layer-pages.md`. `validateTripDraft`를 부르는 곳은 배선 층(`pages/trip-new-step1/`) 하나뿐이고, 시트·다이얼로그는 서버 훅을 직접 물지 않는다. 날짜 산술은 epoch-day 방식이고 `new Date(` 생성자를 쓰지 않는다(기계 강제 없음 — TRIP-1145에서 스캔 삭제). 편집 시트는 전부 `@gorhom/bottom-sheet` 기반 props-only 무상태이고, 개폐·드래프트는 배선이 소유하며 시트는 화면의 형제로 마운트된다 — 실개폐·딤·터치차단은 통과형 목이라 jest 사각(6-b 전용).

| 파일 | 역할 |
|---|---|
| `src/features/trip/model/tripDraft.ts` | 위저드 드래프트 검증. `validateTripDraft`는 위반 코드 **집합**(`NO_DESTINATION`·`END_BEFORE_START`·`NIGHTS_EXCEED_PERIOD`·`PARTY_BELOW_ONE`, 계약에 없는 판정은 발명하지 않음)을 돌려주고 **페일클로즈**다(판독 불가 날짜·`NaN` nights는 통과가 아니다). `nightsSum`(Σ박수)·`toCompanionType`(온보딩 5값→서버 4값, `부모님→null`)·`tripLength`(박수 초과 문구의 분모 — 컨테이너가 재계산하지 않고 재사용). `NaN` 페일클로즈는 PBT 생성기가 못 만드는 입력이라 동결 예제 테스트가 지킨다. |
| `src/features/trip/model/tripSummary.ts` | 위저드 진행 모델(`wizardProgress`·`formatWizardStep`, [1,4] 클램프)과 g01 요약 5행 셀렉터. `summaryDestinations`·`summaryPeriod`·`summaryBudget`은 `SummaryLine({main; sub?})\|null`, `summaryCompanion`은 `{main}`(sub 키 자체 없음 — `toEqual` 여분키), `summaryPreferences`는 `PreferenceSummary({main; onboarding})\|null`. 취향·예산 tier는 스토어에 없어 **인자로만** 받는다(라벨 불가지). 미선택은 빈 문자열이 아니라 `null`. |
| `src/features/trip/model/tripWizardStep1.ts` | 순수 함수 계층 — `PERIOD_PRESETS`·`COMPANION_OPTIONS`·`presetRange(code, baseDate)`·`deriveEndDate(startDate, nights)`(`fromEpochDay(toEpochDay(start)+nights)`)·`fromEpochDay`·`dayOfWeek`. 시계를 읽지 않는다(기준일은 인자). |
| `src/features/trip/model/tripWizardStore.ts` | 위저드 드래프트 **Zustand 스토어**(`useTripWizardStore`, persist 없음 — 모듈 싱글턴이라 재진입 보존이 저절로 성립). 판정은 하지 않는다. `touched`는 오류 문구 표시 게이팅. **제거는 자리 기준**(`removeDestination`·`removeMustVisit` 모두 `findIndex`+슬라이스 — `filter`면 같은 값을 둘 담고 하나 지울 때 둘 다 사라진다). `budgetText`는 사람이 친 원문만 저장하고 프리필은 스토어에 쓰지 않는 파생값이다("프리필 쓰기 ≠ 사용자 입력"). `initMustVisits`는 첫 호출만 반영, `addMustVisits`는 결과가 같은 참조면 `{}`를 돌려 상태를 안 바꾼다(렌더 루프 차단, 개념 [[참조 동일성과 렌더 루프]]). ⚠️ **`resetMustVisits()`는 시드 3필드(`mustVisits`·`mustVisitsInitialized`·`excludedMustVisitPoiIds`)의 손으로 적은 키 목록**이라 새 시드 필드를 추가하면 여기에도 손으로 넣어야 한다(테스트·tsc 모두 못 잡는다). `prefStyleOverride`·`prefActivityOverride`(여행 로컬 취향 두 축 — 같은 라벨 자연·쇼핑이 두 축에 있어 필드가 따로다, TRIP-1092. `undefined`=프리필 사용, `[]`=다 끔)는 사용자 편집값이라 `resetMustVisits`에 넣지 않는다(넣으면 remount마다 삭제). 새 축 필드를 더하면 `INITIAL_DRAFT`(`reset()`) 키와 `src/test-support/wizardDraftFixture.ts`의 채우기에도 손으로 넣어야 한다(픽스처를 빼먹으면 SF-1 자기검사가 red). 종료일은 파생값이다 — `setStartDate`·`addDestination`·`removeDestination`·`setNights`가 비export `endAfter`로 `deriveEndDate(시작, nightsSum)`을 다시 계산한다(`setPeriod`는 파생하지 않는 테스트용 문). ⚠️ 같은 파생이 `TripNewStep1Page.tsx`의 시트 미리보기에도 있다 — 한쪽만 고치면 "시트에 보인 끝 ≠ 적용 뒤 끝". `createdTripId`는 재진입 시 step1 「다음」을 PATCH로 가르는 근거이고, 셸이 마운트마다 지우되 꼭 갈 곳 고르기 완료만 1회성 표식 `preserveCreatedTripIdOnce`(액션 `keepCreatedTripIdOnce`, `INITIAL_DRAFT`에 `false`라 `reset()`이 함께 끔)로 보존한다(TRIP-1113 — 새 진입이 표식을 켜면 `SavedPlacesPage` C1이 red). `INITIAL_DRAFT.companionType`은 `'혼자'`가 기본(TRIP-1045 — `touched`는 안 켜짐, 기본값은 사용자 입력이 아니다). **(TRIP-1042)** `addDestination(name, nights, regionCode?)` — 3번째 인자로 지역 코드를 받아 목적지 객체에 담는다(옵션이라 안 주면 `regionCode: undefined` 키가 생기고 `toEqual`은 무시함, 생성 요청 직렬화에서도 빠짐). `removeDestination`·`setNights`는 `{...one}` 펼치기 복사라 코드가 자동 보존됨(고치지 않음). |
| `src/features/trip/model/mustVisitSeed.ts` | 담은 장소→'꼭 갈 곳' 시드. `seedMustVisits`(첫 등장만, 원본 캐시 배열 불변, 자체 뷰모델 `{sourcePoiId, name, imageUrl}`로 좁힘) · `resolveMustVisitSection`(**시드를 가장 먼저** 보고 로딩·실패·0곳 — 잔존 시드가 실패·로딩 얼굴에 덮이지 않는다) · `mustVisitFailureNotice` · `mergeMustVisitSeeds({current, incoming, excluded})`(current 접두 보존, 추가 전용, 더할 게 없으면 **참조 그대로** 반환). | `src/features/trip/model/regionMatch.ts` | g02 시트 섹션 분리의 주소 판정. `sidoKey(name)` — 끝 명칭을 **긴 것부터** 떼고(`도`를 먼저 떼면 `강원특별자치도`가 깨진다), **접미를 실제로 뗀 경우에만** 3자를 1·3번째 글자로 접는다(시군구 `대덕구`를 접으면 `대구`와 충돌). `addressInRegion(address, region)`. **지역 이름 상수표를 두지 않는다**(소스 스캔 가드가 시도 이름 문자열 0건을 강제). **(TRIP-1042 신규)** `regionCodeInTrip(placeCode, destinationCodes)` — 행정구역 코드 양방향 `startsWith` 판정(짧은 쪽이 긴 쪽의 접두면 안). 장소 코드 없음 → 안(fail-open) · 목적지 코드가 하나라도 없으면 판정 자체를 생략(전부 안, [[fail-open 필터 설계]] "판정 전체를 건너뛰는" 변형). `placeLocationLabel(place, regions)` — 카탈로그 시도 행(코드 앞 2자리)의 `sidoKey`로 접어 `"인천 남동구"` 표기 조립, 못 찾으면 원래 이름·이미 짧으면 안 겹침. 둘 다 `pages/saved-places`가 소비(features 경계상 순수 함수만 export, 화면은 없음). **(TRIP-1074 신규)** `sigunguLabel(address)` — reverse-geocode 주소 문자열의 둘째 토막(시도 버림)이 시·군·구로 안 끝나면 `null`(대체 문구 없음), 일반시+구면 `수원시 영통구`처럼 이어 붙임. 주소 포맷은 계약 없음(관찰 기반, 6-b 실스택 확인 대상) — `pages/trip-new-step2`의 `TripNewStep2Page`가 `useStayAddresses` known 주소에만 호출해 `StaySelectSheet`/`SavedStayCard`로 내린다. |
