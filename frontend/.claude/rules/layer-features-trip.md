# `src/features/trip/` — 계약 계층 + 위저드 1/2 화면 + 제출·오류·예산·숙소 날짜 가져오기·꼭 갈 곳 시드 표면 + 거점 구간 파생 + 거점 배정 화면 2/2 + 거점 지정 전제 게이트 + 여행 기간 박수합 파생 (TRIP-203·204·205·206·207·208·209·224·225·226·368·389)


**여행 생성 위저드 1/2이 TRIP-205로 처음 생겼다** — `ui/`가 이번에 신설돼 `model/`뿐이던 슬라이스가 화면째가 됐다. 서버 계약(orval `trips`·`preferences` 태그)을 도메인 이름으로 감싸는 얇은 층(TRIP-203)·드래프트 검증(TRIP-204)에 이어, 이번 칸은 판정과 렌더를 파일로 가른다 — 순수 계산(`tripWizardStep1.ts`)·상태 상자(`tripWizardStore.ts`, Zustand)·무상태 화면(`TripWizardStep1Screen.tsx`) 셋으로 쪼개 `validateTripDraft`(TRIP-204, 페일클로즈)를 부르는 곳을 배선 층(`pages/trip-new-step1/`) 하나로 좁힌다. **TRIP-206이 그 위에 제출·오류 표면·step2 전이를 붙였다** — `touched`(TRIP-205가 만들고 안 쓰던 상태)를 처음 소비하고, 서버 실패를 `overseas`/`banner` 둘로 분류하는 페일세이프(INV-4)를 더했다(아래 `tripDraft.ts`·`tripWizardStore.ts`·`TripWizardStep1Screen.tsx` 행, 배선 로직은 위 `pages/trip-new-step1/` 절 참고). **TRIP-207이 g01에 예산 블록을 붙이며 `buildCreateTripRequest`의 자동 취향 부착을 사용자 입력 우선으로 반전시켰다** — 신규 순수 모듈 `budgetAmount.ts`(문자열↔정수 판별 유니온 파싱)를 얹고, 프리필은 스토어에 쓰지 않는 **파생값**으로 둬 `onChange` 경로를 안 타게 만든다(아래 `budgetAmount.ts`·`createTripRequest.ts`·`tripWizardStore.ts`·`TripWizardStep1Screen.tsx` 행). **TRIP-208이 등록 숙소에서 날짜를 가져오는 행을 g01에 붙였다** — 판정(`stayDateImport.ts`, 신규 순수 모듈)·표시(`TripWizardStep1Screen.tsx`)·조회·배선(`pages/trip-new-step1/`)을 세 파일로 갈라, 화면이 서버 조회 훅을 직접 물지 않게 했다(`tripWizardStep1Boundary.test.ts`가 소스 스캔으로 강제). 조회 실패는 얼굴을 갈아 끼우지 않고 잔존 목록 위에 재시도 행만 덧붙인다(아래 `stayDateImport.ts`·`useSavedStays.ts`·`tripWizardStore.ts`·`TripGlyphs.tsx`·`TripWizardStep1Screen.tsx` 행, 배선은 위 `pages/trip-new-step1/` 절 참고). **TRIP-209가 담은 장소를 '꼭 갈 곳'으로 시드해 여행 생성 뒤 등록까지 붙였다** — 신규 순수 모듈 `mustVisitSeed.ts`(복사·얼굴 판정·배너 문구)를 얹고, `tripWizardStore.ts`에 1회성 시드 채우기·자리 기준 제거를 더하고, `TripNewStep1Page.tsx`에 `try`를 하나 더 분리해(여행 생성과 must-visit 등록이 각자 실패해도 서로를 오염시키지 않는다) `Promise.allSettled`로 N건을 병렬 등록한다(409는 성공으로 접는다). 제출은 `useRef` 잠금 하나로 등록 중 재클릭·이동 후 재클릭·배너 연타를 전부 막되, 성공 후 이동 시엔 **잠금을 풀지 않는다**(아래 `mustVisitSeed.ts`·`tripWizardStore.ts`·`TripGlyphs.tsx`·`TripWizardStep1Screen.tsx`·`TripNewStep1Page.tsx` 행, 배선은 위 `pages/trip-new-step1/` 절 참고).
