# `src/features/itinerary/` — 일정 생성·초안·같이 짜기·편집·확정의 순수 판정과 화면

생성 방식 선택(h01)·꼭 갈 곳(h02·h03)·생성 진행/폴백(h07)·초안(h11)·같이 짜기(h09·h10)·편집 드래프트·내 여행 목록(h37)·숙소 추천(h15). 판정=`model`, 조립=`pages`, 그림=`ui` 3층 배치이고 화면은 props-only다(배선은 `pages/itinerary-*` 슬라이스). 배럴(`index.ts`)은 없다 — 딥 임포트. `config/` 세그먼트의 카피 상수는 raw-hex/INV-3 소스 스캔(`features/itinerary/ui`만 훑는다) **사정거리 밖**이다 — 거기 색·소요시간을 두면 아무 가드도 못 잡는다(개념 [[가드의 사정거리]]). 지도를 쓰는 화면은 `itineraryMapSurfaceStructure.test.ts`의 `LOCKED_CALLERS`(선 없는 caller는 `NO_LINE_CALLERS`도)에 등재해야 한다.
