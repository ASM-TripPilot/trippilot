# `src/features/itinerary/` — 일정 생성·초안·같이 짜기·편집·확정의 순수 판정과 화면

생성 방식 선택(h01)·꼭 갈 곳(h02·h03)·생성 진행/폴백(h07)·초안(h11)·같이 짜기(h09·h10)·편집 드래프트·내 여행 목록(h37)·숙소 추천(h15 — 뷰모델 타입 `model/stayRecommend.ts`도 화면과 같은 `pages/itinerary/itinerary-stay-recommend`). 판정=`model`, 조립=`pages`, 그림=`ui` 3층 배치이고 화면은 props-only다(배선은 `pages/itinerary-*` 슬라이스). h01 방식 선택·h07 생성 진행/폴백·h11 초안·h09·h10 같이 짜기 화면 뷰와 그 전용 config·래퍼는 TRIP-1150로 `pages/itinerary-{method,generating,draft,copick}`에 이사했다(`layer-pages.md`). h02·h03 꼭 갈 곳·h37 내 여행 목록 화면 뷰는 TRIP-1151로 `pages/itinerary-{mustvisit,list}`에 이사했다 — 이 폴더 `ui/`에 남은 Screen은 공유 `PlaceAddScreen`(itinerary-manual·record-add-visit) 하나다. 공개 API는 `index.ts`와 네트워크 없는 `index.view.ts` 두 진입점이다(TRIP-1157 — 딥 임포트는 lint error). raw-hex·INV-3·지도 호출부 명부 소스 스캔은 TRIP-1145에서 지웠다 — 색·소요시간·지도 `viewOnly` 회귀는 기계 강제 없이 QA 몫이다(`config/` 세그먼트 카피 상수도 마찬가지). TRIP-1155로 파일 22개가 `features/{edit-itinerary,add-must-visit}`·`entities/{itinerary-slot,place}`·`pages/itinerary-{copick,draft,list,manual,stay-recommend}`로 이사했다(행은 각 층 문서).
