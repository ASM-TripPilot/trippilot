# Figma 화면 구조 (밴드 맵)

**어느 밴드를 라이브로 읽을지 판단하는 용도.** 화면 상세(레이아웃·IO·컴포넌트)는 여기 없다 — 라이브 Figma가 유일한 정본이다.

## 파일

- 파일 키: **`1MTF3dtptIrbg8gld5IdO2`**
- 단일 페이지 "화면" = 노드 **`1228:1045`**
- URL 없이 이 키로 바로 읽는다 — 사용자에게 URL을 매번 묻지 않는다.

## 밴드

| 밴드 | 도메인 | 범위 |
|---|---|---|
| `a` | 홈 | first-cut |
| `b` | AI 어시스턴트 | M16 — 밖 |
| `c` | 온보딩·인증 | first-cut (U0) |
| `d` | 탐색 | first-cut |
| `e` | 숙소 | first-cut |
| `g` | 여행 생성 | first-cut |
| `h` | 일정 생성 | first-cut |
| `i` | 여행중·Plan-B | first-cut |
| `j` | 기록·회고 | first-cut |
| `k` | 커뮤니티 | M15 — 밖 |
| `l` | 알림·마이·설정 | first-cut |
| `m` | 공동편집 | M17 — 밖 |

- **`f` 밴드는 없다.** 결번이니 찾지 마라.
- `b`·`k`·`m`은 first-cut 범위 밖 — 해당 밴드 작업 요청이 오면 범위 밖임을 먼저 알린다.
- 화면은 밴드 코드 + 번호로 명명한다(`c01`, `c02`, `d01`…).

## 읽는 절차

1. `get_metadata(fileKey[, nodeId])` — 밴드/프레임 목록
2. `get_design_context` / `get_screenshot` — 대상 화면의 디자인·스크린샷

**토큰 주의**: `get_metadata`로 페이지 전체를 뜨면 1MB를 넘길 수 있다. 대상 노드로 좁히거나, 목록은 최상위 프레임(2칸 들여쓰기)만 추출한다.

## 이 표가 낡았을 때

밴드 구성이 이 표와 다르면 **라이브가 옳다.** 브리프에 `문서-라이브 드리프트: {요지}`를 **명시만** 한다 — 이 파일을 고치는 것은 [기록]의 scribe다(밴드 수준만, 화면 목록은 여기 두지 않는다). [인지]가 사이클 도중 하네스 파일을 고치면 변경 집합이 오염된다.
