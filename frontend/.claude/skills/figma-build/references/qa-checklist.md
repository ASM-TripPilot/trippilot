# Figma 화면 QA 체크리스트

> 화면마다 `get_screenshot`을 **실제로 보고** assertion PASS/FAIL. FAIL은 근거(무엇이·어디서) + 수정안 1줄. 기준 값은 `design-kit.md`(값의 정본은 코드 `tailwind.config.js`). 산출·재호출 규칙은 `figma-build/SKILL.md`.

## A. 색 (킷 §2)
- [ ] 사용 색이 코드 25토큰뿐인가 — 임의 회색·비토큰 hex 없음.
- [ ] 강조는 코랄 `#FF385C` **한 색만** — CTA·♥·활성탭·핀·배지·강조 텍스트. 예외: `info` 청록(정보칩), `success`(완료 상태), `presence-blue/teal`(**협업 프레즌스에서만**). 그 외 blue·보라 = FAIL.
- [ ] 텍스트 위계 = ink/body/muted. 순검정 본문 없음.

## B. 아이콘·플레이스홀더 (원인 1위)
- [ ] **대괄호 플레이스홀더 0** — `[알림] [지도] [핀] [IMG]` 류 텍스트 자리표시 전면 제거.
- [ ] 아이콘은 실제 벡터(파운데이션 Icon 세트 인스턴스 또는 `createNodeFromSvg`). 이모지 남발 금지.
- [ ] 하단탭 아이콘 실재·활성=코랄 채움/비활성=muted stroke.

## C. 사진·지도
- [ ] 회색 빈 이미지 박스 0 — 사진 자리는 실사진(킷 §7 해시) 또는 의도된 모노 면.
- [ ] 사진 위 텍스트는 스크림으로 가독 확보.
- [ ] 지도는 자매 화면과 같은 스타일(킷 §7.5), 마커 수 = 후보 수.

## D. 형태·깊이
- [ ] 카드 16 / 버튼·입력 12 / 칩·pill·검색바 999. 하드코너 없음.
- [ ] 그림자 딱 하나(0.08/4/16). 다단계 두꺼운 그림자 없음.

## E. 타이포
- [ ] 한글 Noto Sans KR / 라틴·숫자 Inter. 굵기 Bold·Regular만. 크기는 코드 램프 8단(26/22/17/15/14/13/12/11).
- [ ] **클리핑 0** — 세로/가로 잘림, 라인하이트 잘림, 카드 넘침 없음.

## F. 레이아웃·구조
- [ ] 하단탭 풀폭(390) 균등 분배, 라벨 안 겹침(폭 붕괴 112px 아님 — 킷 §9).
- [ ] 상단 safe area(~54) 확보, 가짜 상태바(9:41 ●●●) 없음.
- [ ] 겹침·요소 충돌 0. 터치 타깃 ≥44. 간격이 4의 배수.
- [ ] 활성 탭/세그/칩이 현재 화면과 일치.

## G. 상태 커버리지
- [ ] 스펙이 요구한 상태(default 외 empty/loading/error 등)가 존재하고, 빈 화면은 히어로+카피로 채움. 상태 이름은 아래 어휘를 쓴다.

## H. 슬롭 렌즈 (값이 아니라 결정 — 차단 아님, "슬롭 의심"으로 보고)
- [ ] 자매 화면(같은 밴드 신세대)과 나란히 놓고 어휘(카드·칩·배너·FAB·앱바)가 일치하는가. 새 어휘를 만들었다면 이유가 스펙에 있는가.
- [ ] 스펙의 "한 가지 일"이 축소 스크린샷에서 **첫 시선**에 오는가.
- [ ] 기본 조립 패턴에 걸리는가 — 히어로+통계 타일, 번호 배지 남용, `[i]` 배너로 정보 때움, 같은 카드 3연속, 모든 섹션 같은 리듬.
- [ ] 카피: 플레이스홀더(제목/설명/CTA)·시스템 언어("솔버 재검증")·수동태·사과문 없음. 부산 실데이터인가.
- [ ] 이 프레임이 "아무 여행앱에나 붙어도 되는 화면"인가 — 그렇다면 무엇이 TripPilot 고유인지 한 줄 답이 있어야 한다.

## 정본 이식(in-place)일 때 추가
- [ ] 빌드 전 원본 스크린샷(`before-{node}.png`)과 대조 — **정본에만 있던 자산**(예: 영업시간 메타)이 사라지지 않았는가.
- [ ] 새 밴드 모드였다면 정본 프레임 스크린샷이 빌드 전후 **동일**한가(정본 무변경 단언).

## 판정
- 화면당 PASS/FAIL + 항목. high(색 위반·플레이스홀더·클리핑·nav 붕괴·정본 자산 회귀) = 차단 → 빌더 재호출. low = 비고. H = 슬롭 의심(사람 검토).
