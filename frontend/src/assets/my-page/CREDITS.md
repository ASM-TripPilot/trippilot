# 이미지 출처 (src/assets/my-page)

**개발 프리뷰 전용 의도다.** `src/app/_dev/preview.tsx` 의 l03 마이페이지 empty(`my-page-empty`) 픽스처가
"지난 여행" 썸네일 카드 사진 칸을 채우는 데만 쓴다 — 실앱은 사진 원본이 기기 로컬에만 있어(INV-U5-03)
회색 자리만 그린다(TRIP-776, 부모 G7).

**다만 그 의도를 기계적으로 막는 것은 없다.** `_dev/preview` 는 expo-router 라우트이고
expo-router 는 `_` 접두 경로를 라우트에서 제외하지 않는다. 따라서 릴리스 빌드에서도 딥링크
`trippilot://_dev/preview?state=…` 로 이 화면이 열리고, `require` 된 에셋이라 세 파일은 릴리스
번들에 무조건 실린다(`assets/itinerary/CREDITS.md` 와 같은 사정).

## 알아야 할 것

- 세 장 모두 **디자이너가 Figma 목업에 넣은 사진**을 내려받은 것이다(2026-09-25, TRIP-776).
  원저작자와 이용 조건을 확인하지 못했다.
- 그래서 **프로덕션 화면에서는 import 하지 않는다.**
- **릴리스 전에 할 일**: 라이선스가 분명한 사진으로 갈아치우거나, `_dev` 라우트를 릴리스
  빌드에서 제외해야 한다.
- 원본은 1280px 였다. 표시 크기가 64×64 라 긴 변 480px 로 줄여 넣었다.
