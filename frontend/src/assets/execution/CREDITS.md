# 이미지 출처 (src/assets/execution)

**개발 프리뷰 전용 의도다.** `src/app/_dev/preview.tsx` 의 i01 여행중 허브(`live-hub-*`) 픽스처가
done 카드 사진 칸을 채우는 데만 쓴다 — 실앱 허브는 사진 조회 계약이 없어 사진 칸을 그리지 않는다(G6).

**다만 그 의도를 기계적으로 막는 것은 없다.** `_dev/preview` 는 expo-router 라우트이고
expo-router 는 `_` 접두 경로를 라우트에서 제외하지 않는다. 따라서 릴리스 빌드에서도 딥링크
`trippilot://_dev/preview?state=…` 로 이 화면이 열리고, `require` 된 에셋이라 네 파일은 릴리스
번들에 무조건 실린다(`assets/itinerary/CREDITS.md` 와 같은 사정).
