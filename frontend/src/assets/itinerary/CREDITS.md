# 이미지 출처 (src/assets/itinerary)

**개발 프리뷰 전용 의도다.** `src/app/_dev/preview.tsx` 의 h11(AI 추천안 초안) 픽스처가
카드 썸네일 자리를 채우는 데만 쓴다 — 프로덕션 화면은 서버가 준 `imageUrl` 만 그린다.

**다만 그 의도를 기계적으로 막는 것은 없다.** `_dev/preview` 는 expo-router 라우트이고
expo-router 는 `_` 접두 경로를 라우트에서 제외하지 않는다(제외 대상은 `+api`·`+html`·
`+middleware` 뿐). 따라서 릴리스 빌드에서도 딥링크 `trippilot://_dev/preview?state=…` 로
이 화면이 열리고, `require` 된 에셋이라 세 파일은 릴리스 번들에 무조건 실린다.

| 파일 | 출처 | 라이선스 |
|---|---|---|
| `draft-preview-1.jpg` | Figma 와이어프레임 파일 `1MTF3dtptIrbg8gld5IdO2` · h11 목업 카드 1의 사진 노드 `1870:1144` | **확인되지 않음** |
| `draft-preview-2.jpg` | 같은 파일 · h11 목업 카드 2의 사진 노드 `1870:1159` | **확인되지 않음** |
| `draft-preview-3.jpg` | 같은 파일 · h11 목업 카드 5의 사진 노드 `1870:1204` | **확인되지 않음** |

## 알아야 할 것

- 세 장 모두 **디자이너가 Figma 목업에 넣은 사진**을 내려받은 것이다(2026-08-10, TRIP-339).
  원저작자와 이용 조건을 확인하지 못했다.
- 그래서 **프로덕션 화면에서는 import 하지 않는다.** 프리뷰를 Figma 와 눈으로 대조할 때
  사진 칸이 통째로 비어 있으면 대조 자체가 불가능해서 들인 값이다.
- **릴리스 전에 할 일**: 라이선스가 분명한 사진으로 갈아치우거나, `_dev` 라우트를 릴리스
  빌드에서 제외해야 한다. 위의 딥링크 도달성 때문에 "안 쓰니 괜찮다" 로는 닫히지 않는다.
- 원본은 800~1280px 였다. 표시 크기가 78×78 이라 긴 변 480px 로 줄여 넣었다.
