# 지역 커버 이미지 (서울·부산·제주 · 강원·경북·경남)

AI(`gpt-image-2.5-sunburst`)로 만든 수묵담채풍 일러스트 115장. 여행 카드·홈 히어로·지역 카드·숙소/장소 빈 이미지를 채운다.

> **연결됨:** `src/entities/trip/config/regionCovers.ts`(코드→이미지 매핑)와 `lib/regionCover.ts` 가 이 폴더의 `covers/` 107장(서울·부산·제주 46 + 강원·경북·경남 61, TRIP-1805)을 일정 목록·홈·기록·마이·여행 설정과 커버 고르기 시트에 싣는다. `hero/` 중 서울·부산·제주 3장은 홈 히어로 도시 카드(`src/pages/home/model/homeFixtures.ts`, TRIP-1432)가 쓴다. `placeholder/` 의 `place` 는 장소 폴백이 쓴다.
>
> **아직 안 연결됨:** `hero/` 의 강원·경북·경남 3장. 탐색 지역을 열 때 판단한다. 지역을 더할 땐 `regionCovers.ts` 에 한 줄 + `index.json` 에 이름표 한 줄(키 집합이 어긋나면 `regionCover.test` 가 red).

## 구성 (115파일 · 약 9.7MB)

| 폴더 | 수 | 규격 | 파일명 |
|---|---|---|---|
| `covers/` | 107 | 3:2, 738×492 WebP q75 | 지역 코드 — 시도 `11`·`26`·`50`·`47`·`48`·`51`, 시군구 `11680` 등 (서울 25 · 부산 16 · 제주 2 · 강원 18 · 경북 22 · 경남 18) |
| `hero/` | 6 | 6:7 세로, 1024×1195 WebP q80 | 시도 코드 `11`·`26`·`50`·`51`·`47`·`48` — 홈 히어로 도시 카드(TRIP-1432) |
| `placeholder/` | 2 | 3:2 WebP q75 | `stay`·`place` — 숙소·장소 공용 폴백 |
| `index.json` | | | 코드 → 지역 이름 — **앱에 연결된 지역만**. `regionCover.test` 가 이 파일의 키가 `REGION_COVERS` 와 같음을 강제한다 |
| `index-gw-gb-gn.json` | | | 강원·경북·경남 **히어로** 이름표 3개 — 히어로가 아직 연결 전이라 따로 둔다(커버 61개는 `index.json` 으로 옮겼다) |

코드는 서버 `GET /regions` 의 `regionCode`(법정동코드 기반)와 같다. 같은 이름(서울 중구·부산 중구 등)을 코드로 구분한다. **강원은 `51`**(강원특별자치도, 2023~) — 옛 코드 `42` 가 아니다. `covers/` 의 시군은 서버 카탈로그에서 선택 가능한 것만 만들었다 — 포항시·창원시는 시 하나(`47110`·`48120`)이고 구 단위(`47111` 등)는 없다.

## 연결 방식과 알아둘 것

- **구 단위 여행의 홈 히어로는 `covers/` 를 세로(6:7)로 잘라 쓴다.** 소재를 가운데에 그려서 중앙 크롭해도 남는다(합성 확인). `hero/` 3장은 홈 히어로 도시 카드가 쓴다(여행 카드에는 깔지 않는다).
- **일정 카드(`TripCard`) 사진 경로엔 스크림이 없다.** 밝은 일러스트에 흰 제목을 올리려면 좌상단 검정 알파 **0.6**(위→카드 높이 60%까지 0) 필요. 0.5 는 46곳 중 9곳이 대비 2.9~3.0 이다. 홈 히어로는 기존 스크림으로 충분(대비 9~12).
- 여행 카드는 **첫 번째 목적지**의 `regionCode` 를 쓴다. 코드가 없거나(이름만 받은 옛 여행·동명이지역) 위 여섯 시도 밖이면 그라데이션 폴백.
- React Native 는 이미지를 정적 `require` 로만 번들한다 → 코드→이미지 매핑 모듈이 필요하다.

## 알려진 한계

- 그림만 보고 지역을 맞히는 블라인드 테스트 정확도는 약 72~78%. 일반 시장·사찰·공원·산 소재(양천 목동, 금천 가산, 관악산, 북구 구포시장, 연제 고분군, 동래 읍성, 강북 꿈의숲 등)는 소재가 맞아도 그림만으로는 구별이 안 된다. 카드에 지역 이름이 붙는다는 전제.
- 실제 모습과 대조해 못 한 곳: 서울 강서구 서울식물원 온실 형태(접시형으로 그림), 서울대 정문은 형태를 확인하지 못해 쓰지 않았다.
- 부산 대표(`26`)만 황혼 야경이라 다른 카드보다 어둡다(해운대구·수영구와 구도를 가르려고).
- **강원·경북·경남 64장 점검(2026-11-06).**

    - **2차에서 사소한 차이·일치로 둔 곳**: 태백산 주목(주목 수형은 살아 있는 사진을 못 찾아 낮은 확신, 정상 능선은 둥글고 나무가 드묾), 삼척 해양레일바이크(실물은 복선 선로, 차량 두 종류),  포항 호미곶(육지 손은 체크무늬 석단 광장 위), 김천 직지사(진입로 대조 못 함), 구미 금오산(암봉 사진을 못 봐 대조 못 함), 상주 경천대(흰 모래톱은 4대강 사업 뒤 사라짐), 문경 주흘관(앞은 소나무숲이 아니라 잔디 광장), 영덕 풍력(풍력기는 해안 절벽이 아니라 산 능선), 고령 대가야 고분군(일치), 성주 참외(하우스는 불투명 흰 비닐로 완전히 덮임), 예천 회룡포(마을은 현대식 주택, 다리는 곧은 철판 뿅뿅다리), 울진 금강송(아래쪽 줄기는 회갈색), 울릉 독도(동도 꼭대기는 평평한 고원, 뾰족한 건 서도), 창원 여좌천(좁고 얕은 도심 하천), 통영 동피랑(집 전체를 칠한 마을이 아니라 흰 벽에 그린 벽화), 사천 바다케이블카(대방 정류장은 평지 건물), 김해 수로왕릉(정문 숭화문은 크고 우진각), 양산 통도사(삼성반월교 난간에 기둥이 없음), 함안 말이산(봉분에 호석 없음), 창녕 우포늪(개구리밥 융단), 남해 다랭이마을(돌담이 일부, 집은 현대식), 하동 녹차밭(야생차라 보성식 이랑이 아닐 수 있음), 산청 남사예담촌(담 전체에 둥근 강돌), 함양 상림(위천은 넓고 보가 있음), 경남 대표 한려수도(실물은 숲 짙은 둥근 큰 섬 위주), 양구 펀치볼(능선이 완만), 인제 자작나무숲(줄기가 더 굵고 데크는 붉은 갈색), 횡성 풍수원성당(일치), 영월 한반도지형(암벽은 오른쪽 끝에만), 평창 양떼목장(헛간은 푸른 철판 지붕), 철원 한탄강(기둥이 불규칙한 부채꼴), 고성 청간정(높은 석주 위 누마루가 약함), 양양 낙산사(관음상은 평평한 언덕 광장, 의상대는 따로 있음).
    - **한계**: 근거 사진이 계절이 섞여 있어(겨울·가을) 단풍·눈 색은 비교하지 않았다. 춘천 남이섬은 겨울 사진 1장뿐이라 가을 모습(잎 색·밀도)은 대조하지 못했다. 김천 직지사·구미 금오산은 진입로·암봉 사진을 못 받아 형태 대조를 못 했다. 선바위 높이(약 10m)는 한 출처뿐이라 확정하지 않았다. 청량산은 12봉 전체를 한눈에 담은 먼 사진을 못 찾아 윤곽 전체는 대조하지 못했다. 왜관철교 경간 수·보현산천문대 건물 배치(한 장에 함께 보이는지)도 사진만으로 확정하지 못했다.
- 시도 대표는 강원 설악산, 경북 불국사(경주시 커버는 첨성대), 경남 한려수도 섬들이다. 경북 울릉군 커버는 독도(행정구역상 울릉군).

## 다시 만들 때 (`_tools/gen_districts.py`)

스타일 **K6** + 소재 한 줄 + 구도 문구를 조합해 뽑는다. 소재 확정표(`ALT`)와 스타일 문구가 이 스크립트에 있다.

```bash
python3 -I frontend/assets/region-covers/_tools/gen_districts.py K6 11680,26110   # 지정 지역만
python3 -I frontend/assets/region-covers/_tools/gen_districts.py K6 all            # 아직 없는 것 전부
python3 -I frontend/assets/region-covers/_tools/gen_districts.py K6 gangwon,47130  # 시도는 별칭(seoul·busan·jeju·gangwon·gyeongbuk·gyeongnam, 히어로는 -hero)
```

⚠️ `all` 은 `_tools/out/` 에 PNG 가 없는 소재를 전부 새로 뽑는다. 원본 PNG 는 만든 머신에만 있어서(커밋 안 함) 다른 머신에서 `all` 을 돌리면 이미 앱에 들어간 그림까지 다른 그림으로 다시 나온다 — 고칠 곳 코드만 지정해서 돌려라.

- 레포 루트 `.env` 의 `OPENAI_BASE_URL`·`OPENAI_API_KEY`(Azure) 를 읽는다. 모델 `gpt-image-2.5-sunburst`, `POST {base}/images/generations`. 한 장 ~45초, **동시 3개까지**(더 많으면 429 — 스크립트가 쉬었다 재시도).
- 결과 PNG(1536×1024, 히어로는 1024×1536)는 `_tools/out/` 에 쌓인다(커밋 안 함). 번들용 WebP 로 줄이는 건 수작업: 커버 738px q75, 히어로 6:7 크롭 1024px q80.
- **스타일 문구에 `mountains`·`stalls`·`awnings` 를 넣지 마라** — 모델이 모든 그림에 산 능선·노점을 그려 넣는다. 소재에 적힌 것만 그리게 하는 문구("Draw only what is described…")가 들어 있다.
- 소재는 "그 지역 사람이 아닌 사람도 아는 곳인가"로 골랐다. 새로 정하면 소속(행정구역)과 실제 모습을 웹으로 확인한다 — 광나루한강공원은 강동구, 연주대는 과천시, 부산항대교는 영도·남구다.
