# 프로젝트 컨텍스트 — 캡스톤디자인 (경희대 컴퓨터공학과)

> 이 파일은 Claude Code가 세션 시작 시 자동으로 읽는 프로젝트 메모리입니다.
> 최종 업데이트: 2026-07-14 (Cowork 세션에서 이관)

## 나에 대해

- 박준하, 경희대학교 컴퓨터공학과.
- 커리어 목표: **대규모 데이터 + AI 모델 설계 + MLOps를 모두 다루는 풀스택 AI 엔지니어.**
- 현재 소프트웨어 마에스트로 진행 중 (AI 담당): 멀티에이전트, RAG, LangChain, AWS Bedrock 기반 agent AI 설계. MLOps 세팅 예정.

## 캡스톤 프로젝트

- 주제: **로컬 LLM 경량화 → 피지컬 AI(임베디드 디바이스) 임베딩.**
- 핵심 축: ① LLM 경량화/최적화 (quantization, pruning, distillation, efficient inference)
  ② 엣지/임베디드 (on-device AI, NPU/SoC, low-power inference) ③ 피지컬 AI (embodied AI, VLA).

## 지도교수 후보 (조사 완료, 2026-07)

- **1순위: 최성하 교수 (EMIL Lab, emil.khu.ac.kr)** — 효율적 LLM 추론, KV 캐시 압축, 효율적 파인튜닝.
  Qualcomm AI Research 수석 출신(온디바이스 AI 실무), LG전자/LG AI Research 경력. 2026년 3월 부임 신임.
  → 경량화 기술 자체를 깊게 팔 때 최적.
- **1순위(동급): 배성호 교수 (ENC Lab/고효율신경망계산연구실, mlvc.khu.ac.kr)** — 모델/데이터 압축,
  Efficient Embodied AI(VLM/VLA→물리 에이전트)가 연구실 공식 기둥. AAAI/ICLR/CVPR 실적.
  → 피지컬 AI 임베딩 그림 전체로 지도받을 때 최적.
- 2순위: 허의남 교수 — 클라우드·엣지 분산 인프라 중심. 캡스톤 인기 교수지만 모델 경량화 코어와는 방향 다름.
- 컨택 시: 교수님 최근 논문 1편 언급 + "로컬 LLM을 quantization/distillation으로 경량화해
  임베디드 디바이스에 온디바이스 배포하는 캡스톤"으로 한 줄 소개.

## 커리어 전략 (두 프로젝트 역할 분담)

- 소마 = 모델 **위쪽** 레이어 (에이전트/RAG/클라우드 LLMOps) / 캡스톤 = 모델 **아래쪽** 레이어 (경량화/엣지 배포). 서로 보완.
- MLOps는 결을 다르게: 소마 → 클라우드 LLMOps (프롬프트 버저닝, **eval 파이프라인 중심**, 모니터링),
  캡스톤 → 엣지 MLOps (압축 → GGUF/ONNX 변환 → 디바이스 배포 → 온디바이스 성능/메모리 모니터링).
- 교수님에게는 혼자 못 배우는 것(모델 경량화 설계 피드백)을 얻고, MLOps는 프로젝트 안에서 스스로 세팅하며 습득.
- 목표 포트폴리오 한 줄: "에이전트 시스템을 설계하고, 밑단의 LLM을 경량화해 임베디드 디바이스까지
  엔드투엔드로 배포·운영해본 AI 엔지니어."
