# 파일 참조 및 claude.md 관리 규칙

## 읽기 규칙
폴더 진입 시 해당 폴더의 `claude.md`를 먼저 읽고, 필요한 파일만 선택적으로 참조한다.
불필요한 파일 읽기로 컨텍스트를 낭비하지 않는다.

## claude.md 생성 규칙
새 폴더를 만들면 반드시 해당 폴더에 `claude.md`를 생성하고, 그 폴더의 용도를 정의한다.

## claude.md 갱신 규칙
폴더 내 파일이 추가·삭제·수정되면 `claude.md`도 함께 업데이트한다.
- 추가된 파일/내용 → claude.md에 반영
- 삭제된 파일/내용 → claude.md에서 제거
- 항상 현재 폴더 상태와 일치하게 유지
