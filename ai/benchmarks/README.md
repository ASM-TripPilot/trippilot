## 엔티티 해소 임계 캘리브레이션 (TRIP-252)

fuzzy_match 3단 판정 임계(AUTO ≥ 0.85 / CONFIRM ≥ 0.60 / 미만 UNRESOLVED,
`src/trippilot/poi_curation/config.py`)는 remote config 주입값이고, 실데이터 기반
캘리브레이션은 후속 과제다(business-rules §3). **실데이터가 없는 현 단계의
산출물은 캘리브레이션 하네스**: 한국 POI 이름 변형을 모사한 라벨 케이스셋
(`data/entity_resolution_cases.py`, 동일 장소 변형 8 + 유사 다른 장소 6)에
임계 격자를 스윕해 세 비용을 표로 낸다.

- **오자동병합(false-AUTO)** — 다른 장소를 조용히 합침. 최악 (침묵 오류)
- **과잉확인(over-CONFIRM)** — 정답인데 확인 UI 요구. 마찰 비용
- **미해소(miss)** — 정답이 풀에 있는데 UNRESOLVED. 웹 소싱(U6) 낭비

### 초기값 (0.85, 0.60)의 케이스셋 성적 — 2026-08-06 실행

| 지표 | 값 | 내용 |
|---|---|---|
| 정상 AUTO | 3/8 | 오타(성심땅 0.889, 테라로싸 0.875)·공백(1.000)은 자동 확정 |
| 과잉확인 | 3/8 | 지점 접미 생략(0.600)·영/한 혼용(0.600)·업종 접두 생략(0.636) — CONFIRM으로 흡수 |
| 미해소율 | 2/8 (25%) | 괄호 병기(0.556)·지역명 접두(0.571)가 confirm 0.60 바로 아래 |
| **오자동병합** | **1/6** | **D02 "배스킨라빈스 강릉역점" → 강릉점 (0.885 ≥ 0.85)** — 지점명 한 글자('역') 차는 현행 임계로 못 막음 |
| 방어 CONFIRM | 5/6 | 다른 지점·동명 카테고리(0.62~0.82)는 CONFIRM에서 사용자가 기각 |

스윕에서 드러난 트레이드오프:

- `auto`를 **0.90으로 올리면** 오자동병합 0이 되지만, 정상 AUTO도 3→1로
  떨어져(오타 케이스 0.875·0.889가 CONFIRM으로) 확인 마찰이 커진다.
- `auto`를 **0.80 이하로 내리면** 오자동병합 1→3 (유사 상호 0.800, 지점
  접미 추가형 0.821이 자동 병합됨). 0.70이면 5까지 증가.
- `confirm`을 **0.55로 내리면** 미해소 2→0 (0.556·0.571 케이스 구제),
  다른-장소 케이스는 여전히 CONFIRM 방어라 추가 오병합 없음.
- `confirm`을 **0.65 이상 올리면** 미해소율 62%로 급증 — CONFIRM 구간이
  실질 소멸.

**판단: 초기값 0.85/0.60 유지.** 수기 14케이스는 격자의 방향성(단조
트레이드오프)을 보여줄 뿐 임계를 옮길 통계적 근거가 못 된다. 특히 D02류
(지점명 한 글자 차 프랜차이즈)는 임계 조정만으로 해결되지 않는 사례로,
실데이터에서의 빈도가 확인돼야 대응(임계 상향 vs 지점명 토큰 가중)을 정할
수 있다.

### 실데이터 확보 후 재캘리브레이션 절차

1. 운영 로그에서 (사용자 입력, 후보 풀, CONFIRM 응답/기각, 수동 수정) 튜플을
   수집해 `data/entity_resolution_cases.py` 형식으로 라벨링해 추가한다
   (CONFIRM 수락 = gold 확정, 기각 후 재검색 = gold None 후보).
2. `uv run python -m benchmarks.calibrate_entity_resolution` 재실행 —
   오자동병합 0 제약 하에 (과잉확인 + 미해소) 최소 조합을 고른다
   (오자동병합은 침묵 오류라 다른 두 비용과 교환 불가).
3. 선택한 임계는 코드 수정이 아니라 **remote config**(`M7Config.match_auto`
   /`match_confirm` 주입)로 반영하고, 본 문서의 성적표를 갱신한다.
4. `tests/test_m7_calibration.py`가 케이스셋 무결성·하네스 결정론·단조성을
   계속 보증한다 (케이스 추가 시에도 그대로 통과해야 함).
