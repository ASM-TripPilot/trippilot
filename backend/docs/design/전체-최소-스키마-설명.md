# TripPilot 전체 최소 스키마 — 테이블 설명 (데이터 사전)

> 기준일 2026-07-06 · 대상: `전체-최소-스키마.dbml` (35개 테이블, 밴드 a~j)
> 깊이: 개요 — 목적·핵심 컬럼·관계. 제약·인덱스·전체 필드는 유닛 심화에서.
> 공통: PK=`id`(uuid, append-only 로그는 bigint) · 시각=`timestamptz`(UTC) · 배열축=`varchar[]`(NULL=미설정).

## c. 계정·프로필 (M1·M2)

| 테이블 | 목적 | 핵심 컬럼 |
|---|---|---|
| `account` | 계정 정본·생명주기 | `status`(ACTIVE/DELETION_PENDING/DELETED), `age_method`(연령확인), `email`(소셜 제공·nullable) |
| `social_identity` | 소셜 계정 연결 | `provider`(GOOGLE/APPLE/KAKAO/NAVER)+`provider_sub` **유니크**. 계정 식별 기준 |
| `consent_record` | 동의 증적(**append-only**) | `terms_type`·`terms_version`·`action`(GRANT/REVOKE)·`occurred_at`. 현재 동의=최신 행 폴드. 갱신·삭제 없음 |
| `profile` | 프로필 | `nickname`(유니크·2~20자), `onboarding_completed_at`(약관+닉네임 판정) |
| `preference_set` | 취향 7축 | 스타일·활동·이동·음식=`varchar[]` 다중, 예산(tier+원값), 동행(`companion_types[]`+`pet_flag`), `pace`. NULL=미설정 |
| `deletion_schedule` | 삭제 30일 유예 | `purge_at`(=요청+30일), `cancelled_at`. 계정당 1건(활성)·재신청 시 갱신(이력 비보존) |

## d·e. 장소·숙소 (M7·M3·M4·M5)

| 테이블 | 목적 | 핵심 컬럼 |
|---|---|---|
| `poi` | canonical 장소 정본 | `name_ko`·`coord`·`category`·`opening_hours`, `data_status`(ACTIVE/UNVERIFIED/LOST/CLOSED) |
| `poi_snapshot` | 확정 시점 **불변 사본** | `source_poi_id`(값 보존·FK 미강제), 이름·좌표·카테고리 동결. must_visit·slot·visit_record가 참조 |
| `saved_place` | 가고 싶은 장소 위시 | `account_id`+`poi_id`. 여행 생성 시드('꼭 갈 곳') |
| `saved_stay` | **등록 숙소=거점** | 이름·좌표·`check_in`/`check_out`·외부(`external_source`/`id`)·`coord_confirmed`. AI 일정 출발점 |
| `ota_partner` | 제휴 OTA | `code`·`deeplink_template` |
| `outbound_click` | 아웃바운드 클릭 기록 | `saved_stay_id`·`ota_partner_id`·`clicked_at`. 내부 집계 전용 |

> 숙소 위시리스트(WishlistItem)는 MVP 제외 — 등록(saved_stay) 불러오기 / 없으면 검색→등록.

## g. 여행·필수방문지 (M6)

| 테이블 | 목적 | 핵심 컬럼 |
|---|---|---|
| `trip` | 여행 단위 | `status`(PLANNED→CONFIRMED→ACTIVE→ENDED), 국내 destination·날짜(겹침 차단), party·`budget_total`(항공 제외), `deleted_at` |
| `base_assignment` | 등록 거점 + 자연 체류 구간 | `saved_stay_id`·`date_from`/`date_to` |
| `trip_base_day` | **날짜별 기준거점** | `day_date`+`saved_stay_id`(null=여행지 중심)+`resolution`(공백/겹침 해소값). AI 일정 입력 |
| `must_visit` | 필수 방문지 | `poi_snapshot_id`(사본 복제), `type`(ANYTIME 포함/FIXED 시각고정), `fixed_date`/`fixed_start`/`dwell_min` |

## h. 일정 4계층 (M8)

| 테이블 | 계층 | 목적·핵심 |
|---|---|---|
| `itinerary` | — | `mode`(fully_ai/co_plan/manual), `status`(DRAFT→EDITING→CONFIRMED→INTRIP). trip 1:1 |
| `day_schedule` | current | 일자별 컨테이너 |
| `slot` | current | `poi_snapshot_id`↔`saved_stay_id`(**정확히 하나**), `start/end_time`, `source_type`(ai/user/must_visit/stay), `locked`(숙소 등 고정) |
| `plan_snapshot` | plan | 확정 시점 current를 **JSONB로 동결**(불변). 회고 대조용 |
| `generation_session` | — | 생성 진행 상태(preprocess→candidates→hours→route), `partial`(부분결과·'이어서 생성') |

> 4계층: plan=불변 JSONB / current=정규 day_schedule·slot / actual=visit_record / changelog=change_log_entry.

## i. 실행·Plan-B (M9·M10·M18)

| 테이블 | 목적 | 핵심 컬럼 |
|---|---|---|
| `execution_state` | 여행 중 실행 상태 | `current_slot_id`, `mode`(NORMAL/REST). trip 1:1 |
| `trigger_event` | 감지된 변화 | `type`(weather/delay/hours/traffic), `value`, `status`(active/normal/dismissed), `target_slot_id` |
| `replan_session` | 재계획 세션 | `reason`(weather/closed/delay/canceled/fatigue/none), `mode`(ai/manual), `status`(loading→proposed→committed/canceled/undone) |
| `alternative` | 대안 후보 | `source`(ai/manual), `items`·`deltas`(jsonb). 없으면 empty |

## j. 기록·회고 (M12·M13)

| 테이블 | 계층 | 목적·핵심 |
|---|---|---|
| `visit_record` | actual | `status`(upcoming→arrival_pending→in_progress→completed/skipped), `slot_id`(null=즉석), `checkin_type`(auto/manual), `sync_state`(local/pending/synced/conflict) |
| `photo` | actual 첨부 | `storage_key` |
| `memo` | actual 첨부 | `text` |
| `change_log_entry` | changelog(**append-only**) | `actor`·`source_type`(planB/manual/coedit/assistant)·`reason`·`before`/`after`(jsonb) |
| `gps_track` | actual | `polyline`·`distance_m`·`steps`. GPS 옵트인(L3) 전제 |
| `reflection` | — | 일자별 자동 회고(`content`+`stats`), 수동 편집 가능 |
| `trip_summary` | — | 여행 전체 요약(`stats`). trip 1:1 |
| `style_analysis` | — | 여행 스타일 분석(`data`, `sample_trip_count`). **임계 10 방문 게이팅** |
