- [ ] **도메인 이벤트 카탈로그 + 아웃박스 스키마** (`common/core` 계약) — 아직 미작성

- [ ] **에러/응답 표준** + 검증 대응표(클라 Zod ↔ 서버 Jakarta Validation)

## C. 소셜 로그인 선결 (외부 — 이번 스코프 특화) ⭐

소셜 4종 없이는 인증을 구현·테스트할 수 없으므로 **B와 병행 최우선**.

- [ ] IdP 앱 등록 4종
  - Google — OIDC 클라이언트(웹/앱), client id·secret
  - Apple — Service ID + **p8 서명 키**(client_secret을 ES256 JWT로 동적 서명), 이메일 릴레이 정책
  - Kakao — **OIDC 모드 활성화** + REST API 키
  - Naver — OAuth 2.0 앱(OIDC 미지원 — 프로필 API로 sub 매핑)
- [ ] redirect URI · 앱 스킴(`trippilot://auth`) 확정
- [ ] 시크릿 보관: dev=`.env`(git 제외), prod=Secrets Manager
- [ ] JWT 서명 키(JWK 셋) 생성 + kid 체계

## D. 환경·툴링 준비 (걷는 뼈대)

## E. 선결 과제 (추적만 — dev 차단 아님)

- 약관 3종 플레이스홀더 버전(P7) · 금칙어 임시 사전(P8) · 위치정보법 신고(P1, 출시 선결)

## F. 외부 벤더 신청 (U3+ 선결 — 리드타임 있어 조기 착수) ⭐

> U1 스코프 밖이나 승인 리드타임이 있어 **일찍 신청**해 둔다. 승인 대기 중에도 fake provider로 로직 검증(D37). 벤더 확정 근거: `trippilot-docs` decisions.md ADR-0018·0019 / 운영 파라미터 infrastructure.md §21.

- [ ] **링크프라이스** 어필리에이트 가입 + 리워드 API 신청 (리드타임 **1주+**, 수동 승인) — 딥링크·가격피드 소스. 전환게이트는 후속 이연
- [ ] **공공데이터포털 기상청** 활용신청 (리드타임 **1일+**) — 단기예보·기상특보, 격자 nx·ny 변환
- [ ] **카카오 개발자** 앱 등록 + 카카오맵 사용 설정 권한 (즉시~) — 장소·지오코딩. 폴백 네이버
