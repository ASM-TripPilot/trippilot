# TripPilot 개인정보 처리방침 (초안 v0.1)

> terms_type: `PRIVACY_POLICY` · 개인정보 보호법 제30조 + 위치정보법상 개인위치정보 처리방침(위치 절 통합).
> 시행일: [미확정: 공개 출시일]

TripPilot(이하 "서비스")을 운영하는 송승윤(이하 "운영자")은 이용자의 개인정보를
소중히 다루며, 개인정보 보호법 및 위치정보의 보호 및 이용 등에 관한 법률에 따라 아래와 같이
개인정보를 처리합니다.

## 1. 수집하는 개인정보와 목적·보유기간

회원 탈퇴를 요청하면 **30일의 유예기간** 후 아래 항목이 파기됩니다. 유예기간 내 철회하면
계정이 복원됩니다(단, 이미 즉시 파기된 항목은 복원되지 않습니다). 개별 항목의 더 짧은
보유·즉시 파기는 표에 따로 적었습니다.

| 항목 | 수집 시점 | 목적 | 보유기간 |
|---|---|---|---|
| 소셜 계정 식별자(구글·카카오·네이버) | 회원가입 | 회원 식별·로그인 | 탈퇴 + 30일 |
| 닉네임·프로필 | 가입·설정 | 서비스 내 표시 | 탈퇴 + 30일 |
| 로그인 세션(토큰) | 로그인 | 로그인 유지 | **탈퇴 요청 시 즉시 폐기** |
| 여행 취향(온보딩 선호) | 온보딩·설정 | AI 일정 개인화 | 탈퇴 + 30일 |
| 저장한 숙소·장소 | 이용 중 | 탐색·일정 생성 재료 | 탈퇴 + 30일 |
| 여행·일정 정보 | 이용 중 | 일정 생성·재계획 | 탈퇴 + 30일 |
| 방문 기록(방문 체크·좌표*) | 여행 중 | 여행 기록·일정 재계획 | 탈퇴 + 30일 |
| 사진 메타정보(촬영시각·위치정보*) | 사진 첨부 | 여행 기록 | 탈퇴 + 30일 (사진 원본은 기기에만 저장, 서버 미보관) |
| 방문 메모·회고·여행 요약·스타일 분석 | 이용 중 | 기록·개인화 | 탈퇴 + 30일 |
| 알림 내역·푸시 토큰·알림 설정 | 이용 중 | 알림 전달 | 탈퇴 + 30일 (무효 토큰은 확인 즉시 삭제) |
| 동의 이력·위치정보 확인자료 | 동의·위치 처리 시 | 법정 보존 | 아래 위치정보 절 참조 |

\* 표시는 개인위치정보 — 아래 **6. 위치정보의 처리** 절이 함께 적용됩니다.

## 2. 수집 방법

- 회원가입 시 소셜 로그인 제공자로부터 제공받는 정보
- 서비스 이용 과정에서 이용자가 직접 입력·저장하는 정보
- 사진 첨부 시 사진에 포함된 메타정보(위치정보는 별도 동의가 있는 경우에만 저장)

## 3. 처리 위탁 및 국외 이전

| 수탁·이전받는 자 | 이전 항목 | 목적 | 국가 |
|---|---|---|---|
| OpenAI · Anthropic | 방문 기록·여행 취향·일정 정보(AI 일정·회고 생성 입력) | AI 콘텐츠 생성 | 미국 |
| Expo(Expo Push Service) | 푸시 토큰·알림 제목/내용 | 푸시 알림 전달 | 미국 |
| 카카오 | 소셜 로그인 인증 정보·지역명 검색어 | 인증·지역 확인 | 대한민국 |

숙소 예약을 위한 외부(OTA) 링크 이동 시 **서비스는 개인정보를 제공하지 않습니다** —
링크 이동 이후의 예약·결제는 해당 사업자의 약관과 처리방침이 적용됩니다.

## 4. 파기 절차 및 방법

- 탈퇴 요청 시: 세션 즉시 폐기 → 30일 유예 → 위 1항 목록 일괄 파기(전자적 파일 삭제)
- 탈퇴 요청과 무관한 즉시 파기: 사진 위치정보(위치 기록 동의 철회 시)
- 파기 대상 목록은 데이터 구조 변경 시 자동 검증으로 최신 상태를 유지합니다

## 5. 이용자의 권리

- **내 데이터 내려받기**: 설정 > 데이터 내보내기에서 본인 데이터 전체를 파일로 받을 수 있습니다
- 동의 철회: 각 선택 동의(위치 기록·마케팅·개인화)는 설정에서 언제든 철회할 수 있습니다
- 계정 삭제·철회: 설정에서 요청하며, 30일 이내 철회 가능합니다
- 14세 미만은 가입할 수 없습니다(가입 시 연령 확인)

## 6. 위치정보의 처리 (위치정보법에 따른 고지)

1. **처리 목적·보유기간**: 방문 체크 좌표·사진 위치정보(EXIF)를 여행 기록과 일정 재계획
   목적으로 처리하며, 회원 탈퇴 + 30일까지 보유합니다. 위치 기록 동의(선택)를 철회하면
   이후 수집이 중단되고 **이미 저장된 사진 위치정보는 즉시 파기**됩니다.
2. **수집·이용·제공사실 확인자료**: 위치정보법 제16조 제2항에 따라 위치정보시스템에 자동
   기록·보존하며, 보존기간은 **기록 시점부터 6개월**입니다. 확인자료에는 원시 좌표를
   포함하지 않습니다.
3. **파기 절차·방법**: 위 4항과 같으며, 위치정보는 동의 철회·계정 삭제 시 우선 파기됩니다.
4. **제3자 제공**: 개인위치정보를 제3자에게 제공하지 않습니다. AI 콘텐츠 생성을 위한 처리
   위탁(3항)은 제공이 아닌 위탁으로서 고지합니다.
5. **지정 제3자 제공 시 즉시 통보**: 해당 기능을 제공하지 않습니다(제공 기능 도입 시 본
   방침을 개정하고 즉시 통보 수단을 함께 고지합니다).
6. **8세 이하 아동 등의 보호의무자 권리**: 본 서비스는 14세 미만의 가입을 받지 않으나,
   위치정보법 제26조에 따른 보호의무자의 권리 행사는 아래 연락처로 요청할 수 있습니다.
7. **위치정보관리책임자**: 송승윤 (전화 010-7154-8055 · 이메일 trippilot.asm17@gmail.com)
